`DisplayCandidateAudit.json` 还发现候选清单有 633 组完全重合的相同来源、变换和材质，分别来自 324 个文字和 309 个曲线对象。下一版只排除这些可证明重复的显示副本。其他位置不同的实例仍要保留；该统计不能证明其他重叠项安全。

`NR12MaterialAudit.json` 对候选清单中的北侧通道做了细分：749 个对象均无 UV，其中 730 个的已连接材质槽使用程序节点和世界位置，280 个使用物体随机值；19 个只使用常量 Principled 材质。统计按材质槽进行，不代表逐面用量。不要对所有无 UV 对象统一展开，也不要用同一种白材质替代。

`NR12SourceWindingAudit.json` 检查了这 749 件原始网格的闭合面：722 件有向内的闭合部分，27 件为向外的闭合部分；没有发现开放部分或负世界变换。该检查发生在修改器求值之前，不代表全图结果。批量导出应逐封闭连通部分判断方向，仅对需要修正的导出副本反转，再检查求值网格和回读结果。

不得无提示地丢弃程序噪声、磨损、凹凸、发光或玻璃节点。保留 UV0 和原贴图色彩空间。需要新光照 UV 时单独生成，不覆盖源 UV0。

源文件的 201 张图像均已从 packed 数据提取并核对本地字节，共 183 份不同内容。`PackedTextureManifest.json` 记录原图像名、哈希、色彩空间和透明度。`TextureUsageAudit.json` 的 286 个图像节点均找到对应原始文件；其中 283 个连接到材质输出。字节相同的图像没有不同的色彩空间或透明度设置。提取文件是可从源文件重建的本地中间数据，尚未复制进 Unity。

## 北侧通道代表样本

`NR12Pilot_Corrected` 包含墙、灯壳、LR06 暖色灯罩各一件。原始三件闭合网格均为反向绕序。仅在导出副本翻转三件闭合网格；源文件不变。FBX 回读后法线方向正确，三个包围盒最大误差约 0.000123 米。该结果只适用于这三件样本。

只对使用程序材质的墙与灯壳生成烘焙 UV。颜色和粗糙度已烘焙；正常强度凹凸使用浮点法线图保留微小变化。额外的夸张凹凸对照确认烘焙路径会响应凹凸输入，不表示与原材质已目视等价。灯罩不依赖贴图，保留无 UV，并记录 Blender 发光色 `(1, 0.68, 0.38)` 和强度 `2`。这不是 Unity 强度验收值。

`GeometryQA.json` 使用世界坐标计算体积时可能因精度损失错误报告反向。应以 `RoundTripQA.json` 中平移到局部原点后重测的有符号体积为准。多角度图片只是孤立三件的形态检查；不代表完整通道、光照或 Unity 实机。

三件样本已导入独立预制体 `Assets/MoonEnvironment/Variants/LR06Pilot/Prefabs/NR12_Corridor_LR06_Pilot.prefab`，没有接入正式地图。Unity 导入需绕 Y 轴旋转 180 度，三件包围盒最大误差 0.000441 米。URP 材质引用、贴图通道与暖色发光开关已检查。隔离 Editor 预览检查了灯罩及墙体两侧；预览光源为临时示意，不能视作真实烘焙或正式画面验收。原活动场景未保存或修改。

同一 Blender 孤立场景中，以相同相机和灯光分别渲染源节点及样本贴图，各 64 采样。约 34.9 万个可比较像素的解码 PNG RGB 平均绝对差为 0.00533，95 百分位为 0.00393。图中仍有采样噪点；此对照只覆盖三件样本，不是 Unity 或全图材质验收。Unity 预览与源完整场景使用不同灯光，不直接比较亮度。

另有双对象共享图集样本 `Assets/MoonEnvironment/Variants/LR06AtlasPilot`。墙和灯壳共用一个 URP 材质，暖色灯罩仍独立且无 UV。三组临时灯光下的 Unity 预览与单独贴图样本平均像素差为 0.00037–0.00109。源墙与同名 FBX 墙的 Object Info Random 数值一致。以上只覆盖样本，不代表所有实例或完整场景已匹配。

共享图集会改变各物体的贴图密度。本次墙体中位密度从约 26 增至 52 像素／米，灯壳从约 142 降至 52 像素／米。不能只按对象数量分组；应同时检查尺寸和可见细节。浮点图像直接由 Blender 保存为带透明通道的 PNG 时，金属度可能受透明度影响。`nr12_atlas_png.py` 从已保存的独立通道重新打包，并检查实际 PNG 值；样本有效区域的金属度及光滑度误差均为零。

URP 材质导入会根据全局光照标记重算 `_EMISSION`。将其设为 `None` 会使灯罩发光关键字被关闭，即使颜色值仍在。样本使用 `BakedEmissive`，并在重新导入后核对发光关键字。

仍须核验样本法线贴图方向、源材质细节及与正式地形的关系。烘焙只包含小范围相邻遮挡；不能将其视作全场景 AO 等价。源灯的 Blender 功率不能直接作为 Unity 光强。
