# 手雷动作源

右手握雷。安全持有时左手放下。准备投掷时，右手移到肩侧，空闲左手伸向投掷方向。左手食指指向目标，拇指自然收拢。松手后右手投出。不要用持雷手承担瞄准手势。

源文件为 `ArtSource/DollSinger/GrenadeGestures.blend`。本机 Blender 5.2.2 LTS 保存。只改骨骼动作，没有改人物或道具网格。源文件使用 Git LFS。

| 动作 | 源帧 |
| --- | --- |
| 安全握持 | 1–2 |
| 准备及瞄准 | 21–54 |
| 远投及收势 | 81–141 |
| 低抛及收势 | 161–221 |

日常修改直接编辑该 Blender 文件。保存后，用本机 Blender 运行 `Tools/Blender/export_grenade_runtime.py`。它只读源文件，导出洛天依姿态，并按实际骨架和手指轴适配初音、诗岸。运行 Unity 的 `GrenadeAnimationSetup.BakeAll()` 导入。源 SHA-256 保存在 JSON 和 `Export.json`。`grenade_gestures.py` 仅供明确重建源动作时使用，会覆盖该动作源。

右手掌面取 `-Cross(食指根到小指根的横向, 手腕到中指根的前向)`。道具中心位于掌内，纵轴跟随手的横向；不能把道具横放在手背侧。世界位置按米计算，模型缩放只补偿一次。运行时不解 IK，不移动角色根或腿骨。

`review_grenade_gestures.py` 检查已保存的掌面、空手瞄准方向与原网格一致性，并输出材质和细线框预览。结果在忽略目录 `LocalData/GrenadeReview/Blender`。手腕离线适配误差低于 0.001 毫米。Unity 另检查实际角色、握持方向、手指弯曲和道具释放。

参考网格保留原资产：人物 119814 三角形、13 个材质；能量雷 4082 三角形、4 个材质，约 8.9×8.1×15.9 厘米。只读几何检查报告了既有能量雷的 88 对共面贴片、61 对背靠面和 8 个多边形面。这些网格与正式原件的顶点、索引哈希完全一致，本次没有导出或修改网格。手持物离地属于预期。这里不宣称已修复这些既有网格问题。
