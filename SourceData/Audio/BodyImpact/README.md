# 身体命中拟音

- 来源：[10 Impact/Shield Blocks](https://opengameart.org/content/10-impactshield-blocks)。作者 StarNinjas。授权 CC0 1.0。
- 作者用击打纸板录制。此处用作衣物覆盖下的闷击。不是人体受伤录音。
- 保留原文件 impact.1.ogg 至 impact.3.ogg。成品裁去录音空白，保留原速度和音高，滤除低频噪声及尖锐高频。
- 原金属盾牌素材只用于近战格挡。普通受击、近战身体命中及四个枪械身体命中库使用新实录。
- 重建：`Tools/Audio/build_body_impact_audio.py`。绑定：`MoonkovBodyImpactAudioSetup.Install()`。来源和哈希见 `BodyImpactSources.json`。
