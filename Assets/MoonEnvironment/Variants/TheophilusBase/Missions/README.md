# MC00 任务作者资产

正式场景只新增 `MC00MissionSite.prefab` 的一个实例，复用原有 MC00 房间与硬件作为空间锚点，不改变原灯光按钮。

- `RaidMissionSite` 内有可编辑锚点、候选任务模板、随机种子（0 为每会话随机）、发现范围与声效引用。
- 五处物理设备具备可编辑层级、状态条、线路开关、切割部件、样本/档案输出和事故时间标记；两配电柜同时用于档案校验。
- `Authoring.txt` 记录原始锚点与站位。地面、角色净空和视线通过作者检查；完整游戏遍历和联机证据以任务实施状态为准。
- 原创六面结晶网格与原生 Painter2D 图标保持同一形状；没有覆盖既有光环、器官或量子处理器外观。
- 两段 WAV 是 `RaidMissionAuthoring.Sound` 以确定性谐波生成的原创单声道 22050 Hz 循环，无外部录音。SoundDef 沿用现有声音池、SFX 混音与空间衰减；音频听感仍需实际游戏验收。

重建入口：`Tools > Moonkov > Missions > Install formal MC00 hardware`。该工具只接受空闲 Edit Mode、不允许有未保存场景，并拒绝重复安装。已有内容直接编辑预制体和锚点，不要删除整个正式地图重做。
