# 五种液态程序化生物

打开 `Scenes/MC00LiquidMenagerieLab.unity`，或菜单 **Tools → Umbrella Spider → 11 - Open five liquid creatures**。独立副本直接使用 MC00 的实际建筑与碰撞，不修改蜘蛛、蛇、毛毛虫场景，也不进入正式游戏的 Build Settings。

点击画面取得控制：WASD 按镜头方向移动，Shift 加速，鼠标环绕、滚轮缩放，Esc 释放鼠标。**F1** 依次切换触手兽、蜈蚣、水蛭、黏液兽、根须寄生体；**F5** 在同姿态实体和 GPU 液体之间切换；**F3** 关闭 / 恢复骨架吸引；**F2** 对比重黏滞与原流体参数；**Space** 演示物种动作。F6 自动往返、F7 原角色观察、F9 慢动作、F10 复位、F12 停住，`=` 收肢脱离、抛出并落地。

## 五种不同的推进与动作

- **触手兽 Tentacle**：八条连续弯曲触手，接触端交错抓住地面或墙面；身体前进时保留接触锚点，摆动端预测下一抓点，远离身体的旧抓点主动释放。推进速度带拖拽节奏，抬起的末端弯卷；Space 向前探抓并抬起前侧触手。
- **蜈蚣 Centipede**：二十二节连续身体沿走过的路线跟随，四十条腿按从前向后的相位波摆动。支撑足保留碰撞体局部锚点，下次落足带速度预测。头部有成对颚钳与长触须；冲刺 / Space 抬起头颈。
- **水蛭 Leech**：前端伸展时后吸附端保持锚点，前端暂停时后端收缩跟进，身体形成连续拱背；不以毛毛虫足步代替吸附。头部有连续吸盘口缘；Space 增强前端扑伸。
- **黏液兽 Slime**：扁平中心体积与六条伪足共用粒子体积，伪足轮流探出并留下支撑点，主体向运动方向伸长，截面相应收缩。伪足积液波、自由粒子和连接丝产生分流 / 汇合观感；Space 压平主体并拉开前侧伪足。
- **根须寄生体 Roots**：六条主根与六条次级分叉，从中心向末端展开；主根抓地带动缓慢爬行，次级根随主根运输。Space 让前根与分叉抬起、卷曲，形成缠绕姿态。

## 参数与共同液体

选中场景中的 `ProceduralMenagerieExperiment`。Inspector 分别保存五组体形 / 运动及五组液态参数。触手数量、伸展距离、根部 / 末端粗细、中心体积、抓点预测、支撑比例、摆动高度、卷曲、跟随阻尼、变形和主动动作参数均可调。蜈蚣 / 水蛭沿用 `CreatureChainSettings`，可调体长、体节、足列、频率、收缩、拱背、颚钳 / 口缘与触须长度。

材质、运动、吸引、黏度、压力、积液和拉丝调节实时应用。修改影响静止体积的体形或拓扑时，仅重建当前实例的网格 / 粒子引导，先关闭旧渲染器再释放资源；切换物种清理接触与资源，不清除当前身体位置。Play 调参退出后还原，要永久保存需在 Edit Mode 调整并保存场景。

分叉生物通过 `BranchCreatureRig` 解接触和连续截面，`BranchFluidPresentation` 生成填充体积及权重，重用现有 `SkeletonFluidPresentation` 的 GPU 邻域解算、碰撞、密度表面和拉丝。中心、触手、末端、子分叉均从实际姿态生成矩阵，不用 CPU 粒子回读驱动玩法。主体与细丝共用原有湿膜材质和反射处理。蜈蚣 / 水蛭复用链体液态引导；口部和触须也进入同一粒子体积。

分叉骨架最多 239 个引导节点；二十四对足的链体最多 242 个节点。GPU 粒子上限仍为 16,000，体积网格 128³，同一时刻只运行选中的生物。运行中复用姿态和网格数组；形体切换与参数导致的拓扑重建会分配资源。

液态参数新增 **Body / Tip Acceleration Limit、Body / Tip Speed Limit** 和 **Appendage Mass**：前四项控制液体高速追赶骨架的上限，最后一项控制肢体相对主体的密度沉积量。旧实例默认沿用原来的 240 / 420 加速度和 28 / 40 速度上限、肢体积液倍率 1；蜈蚣有独立快速引导预设和较低足列积液倍率，避免四十条腿相互糊成厚团。关闭吸引时仍使用自由流体解算。

## 验证与边界

菜单 **12 - Probe five liquid creatures** 在一次有界 Play 中检查五种生物的粒子有限值、取消吸引后散开 / 恢复后聚回、实际移动、实体同姿态回退、抓点滑移和手动脱离。产物在 `Library/BuildValidation/Menagerie`；仅四个明确阶段读取 GPU 状态，录像捕获不属于正常玩法。

2026-10-13 的 MC00 有界检查：触手兽 6,871 粒子 / 8 抓点，蜈蚣 5,724 粒子 / 40 条腿，水蛭 3,026 粒子，黏液兽 7,905 粒子 / 6 抓点，根须 5,269 粒子 / 205 引导节点。最终五种的粒子和引导均有限值，聚散与实体同姿态回退通过，手动释放后重新落地；已记录的足 / 抓点锚点滑移为 0。修复了水蛭末端 `sin(pi)` 的浮点负尾值进入分数幂导致的 NaN；蜈蚣单独调整高速追赶和足部密度沉积。首轮 `report.json` 保留发现的问题，链体修复结果在 `chain-report.json`，最终蜈蚣结果在 `centipede-report.json`。这轮路线没有跨面计数，因此不能据此宣称五种的整栋楼跨面检查已经完成。

这是离线外观与运动实验。Space 是动作演示，没有伤害 / 抓取玩家 / 战斗 AI / 联网。根须由预先限定的分支拓扑逐渐展开，不是无限植物生成。黏液兽的分流是共同粒子体积的聚散，不能保证穿过任意窄门缝；身体控制器仍使用已有的固定碰撞半径。触手抓点及身体碰撞是有限预算近似，持续自缠绕、极窄夹缝和高速度复杂转角仍需针对场景验证。
