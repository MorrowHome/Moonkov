# 程序化蛇与毛毛虫

新增的五种独立生物实验见 `MENAGERIE.md`：触手兽、蜈蚣、水蛭、黏液兽和根须寄生体。它们使用独立场景和控制组件，本页两个物种及其回退场景继续保留。

实体回退场景为 `Scenes/MC00CreatureLab.unity`（菜单 7）；液态场景为 **`Scenes/MC00LiquidCreatureLab.unity`**（菜单 **9 - Open liquid snake and caterpillar lab**）。这是原 MC00 实验场景的独立副本；蜘蛛与液态蜘蛛场景不受影响，正式游戏场景和 Build Settings 不变。

点击画面取得控制，WASD 按镜头方向移动，Shift 加速，鼠标环绕、滚轮缩放，Esc 释放鼠标。**F1 切换蛇 / 毛毛虫**，**F5 切换实体 / 粒子液体**，F2 切换重黏滞 / 原流体风格，F3 关闭或恢复骨架吸引，F6 自动往返，F7 用原角色观察，F9 慢动作，F10 复位，F12 停住，`=` 脱离并落地。切物种时保留已经走过的弯曲路线与头部位置，重绑腹足和液体；切实体 / 液态不改变身体路线或足点。

## 两种运动

- **蛇**：头部控制方向，身体按走过路线的弧长依次跟随；转角从头传向尾。侧向弯曲波沿身体传播，头尾有不同振幅，尾部逐渐变细；移动停止后波幅逐渐收敛；冲刺抬起头颈，偶尔吐出分叉舌。身体是每帧重建的连续网格，背腹分别着色。
- **毛毛虫**：移动速度随推进周期变化，纵向收缩波让体节依次靠近并鼓起，局部抬起形成拱背。腹足采用碰撞器局部锚点，支撑期间保持落点、摆动期间抬脚；根据根部速度预测下次落点，过度拉远时提前重落；脱离时收足，落地后重新绑定。体节沟槽与不等长刚毛由代码生成。

`ProceduralCreatureExperiment` 在 Inspector 中分别保存 **Snake** 与 **Caterpillar** 两套参数：长度、半径、体节数量、头部比例、速度、转身、波幅、波长、频率、收缩、拱背、腹足、刚毛和材质。运动及外观参数在 Play 中实时应用；刚毛数量变化时才重建对应拓扑。镜头初始参数在进入 Play 时读取。Play 调参为临时修改，长期保存需在 Edit Mode 调整并保存场景。

## 与蜘蛛共用的骨架吸引液体

`ChainFluidPresentation` 为连续脊柱、独立头部以及腹足的根 / 中段 / 足端生成体积粒子和权重；重用 `SkeletonFluidPresentation` 的 GPU 邻域压力、聚合、黏度、重力、障碍投影、三维密度重建与 `FluidFilaments` 的粒子牵连丝。默认蛇约 3,500 粒子，毛毛虫约 4,500 粒子，体积网格为 128³；运行时足部目标直接来自实际腹足锚点，不另造漂移的脚尖骨架。毛毛虫的刚毛在液态中变为稀疏的粒子须丝。液体可以散开、沉积和重新聚回；不是给连续管状网格加波纹。

液体窗口以身体中段为中心，随长度配置边界；头部、身体及足部使用同一重建体积。共享解算保留蜘蛛的默认 89 骨骼、96³ 体积、2.8 m 半边界及原资源读取入口。每个实例分别持有其粒子、密度纹理、计算着色器和材质；切形体或复位时先隐藏旧渲染器再释放 GPU 资源。

Inspector 的 **Snake Fluid / Caterpillar Fluid** 分别控制吸引、阻尼、黏度、压力、积液量、拉丝和材质；其中 **Mantle** 对应头部，**Root / Knee** 对应身体前部 / 中部，**Toe** 对应尾端与腹足。外观或体形变化会重建相应静止体积，运动与材质调节实时传入现有实例。

主体和连丝声明相同的 `Color` 底色属性，统一线性色彩转换、反射探针混合 / 盒投影、湿膜计算和雾坐标。丝线使用 12 边、17 截面的连续管面，法线考虑根部膨大与收颈斜率，并在接近主体表面时混合密度法线；补充正常的阴影偏移和深度法线通道，避免原来偏浅的粗糙线网。

## 身体约束与边界

这是两个离线运动和外观实验，没有接伤害、感知、战斗 AI 或联网。头部复用 `SurfaceMotor` 的跨面运动与脱困，身体保存有限长度的世界路线，逐段接地；对环境做半径扫掠与滑动，支撑面由表面投射负责，非相邻体段做有界分离，关节限制防止邻近截面反向折叠。腹足提前接住运动中的身体。遇到停止推进时自动脱离，手动 `=` 也会清掉接触并收足。

身体约束与液体都是有限预算近似，并非精确肌肉或完整软体动力学；复杂狭缝、持续缠绕和高速大幅换向仍需针对实际场景调整。不能把这条 MC00 路线通过当成所有复杂转角都不会穿插的保证。

菜单 **8** 在一次 Play 中分别验证实体运动；菜单 **10 - Probe liquid chain creatures** 在一次 Play 中分别检查静止聚附、取消吸引、重新聚回、实际跨面、实体同姿态回退。输出 `Library/BuildValidation/ProceduralCreatures/fluid-report.json`、聚散和移动截图与原始视频帧；仅在上述阶段做明确的 GPU 状态读取。正常玩法不读取 GPU 粒子，每帧复用身体、足部和变形数组，不生成新的 GameObject。

## 当前有界验证记录

液态 MC00 场景的出生检查覆盖头部、完整身体后方长度、腹足两侧和沿途地板，已避开原来柜体中的出生位置。本轮蛇前进约 20.35 m、毛毛虫约 5.54 m，两者未失去身体支撑、未触发脱离；粒子没有非有限值，取消吸引后偏离引导场、恢复后重新聚回，实体同姿态回退一致。

共享代码回归的原蜘蛛仍为 5,731 粒子，聚散与回退通过，完成 6 次跨面，最大足点误差为 0、最终恢复数为 0；旧探针另记录 1 帧腿障碍，不能声称该严格脚部检查全通过。Console 的既有 Package Manager path 报错仍在，未作为新生物运行错误处理。尚未验证完整游戏战斗、联网或所有地图的复杂夹缝。
