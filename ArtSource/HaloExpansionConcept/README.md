# 六种光环美术参考

用户反馈已否决下述首版细线方向。新版以 `Arsenal-Six-Filled-Concept.png` 和 `Prompt-Filled.txt` 为准，要求实心平涂块面、有面积的主形与更强的双臂动作张力。

2026-10-21 使用内置 imagegen 工具生成 `Arsenal-Six-Concept.png`，作为 [六种新武器策划](../../Docs/Planning/HaloArsenalExpansion.md) 的轮廓和手势参考。画面从左到右、从上到下为蝉鸣／三律／天枢／望舒／星棘／坠日。

这是概念参考，非 Unity 实测截图、生产透明纹理或已验证的手部动作。实际手势仍以 Blender 原骨架制作和 Unity 四机位验证为准。星棘概念图含六条长刺，生产资源按策划采用五针／五芒花，不能从概念图的装饰数量推导弹体数量。

最终生成提示词保存在 `Prompt.txt`；背景、版式和手部小稿用于沟通，生产资产由独立透明 PNG／部件和材质组成。
