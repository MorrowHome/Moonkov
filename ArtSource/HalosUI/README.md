# Halos 登录与加载动画

源项目为 Halos 仓库的 `Moonkov UIs`。版本和源文件哈希见 `source-manifest.json`。

- 保留原三角标志、终端窗口和噪声。原 GML 放在 `objects`。
- Unity 资源在 `Assets/Resources/Moonkov/UI/Halos`。标志只裁出上半部分，移除图片中的账号和密码文字。噪声缩到 1024×576。终端底图保持原图。
- `MoonkovWordmark.svg` 是本次新增的游戏字标。输入框底线来自原登录图。
- `SignalResidual.png` 用内置 Image 工具在原噪声上补蓝色显影。原标志、窗口底图和位置不改。生成说明见 `signal-prompt.txt`。用户的参考图不作为项目背景导入。
- 动画由 `HalosTerminalBackdrop` 驱动。登录开场可点击跳过。地图加载只跳过装饰，不跳过真实加载。
- 不导入 Halos 中与本任务无关的武器原型。
- 2026-11-07 同步 `2511cfa` 的黑底终端原图。登录和加载共用这张图。蓝色干扰、交互强调和进度条保留。蓝色是有意的美术设定，概念图只用于对照风格。新版三屏舱室主界面另行接入。
- 同日恢复原 GML 的动画节奏。按用户选择，仅去掉开头 260 帧纯黑等待。后续按 60 Hz 换算，保留 523 帧，约 8.7 秒。帧数以首个终端出现为零点。
- 十个终端在第 `0、60、112、156、192、220、240、252、256、257` 帧出现。直接弹出，不淡入。每帧打一个字符，换行不占打字时间。首窗停留 350 帧，后续按 `300 - 20 × 序号` 停留；随后每帧衰减六分之一，低于 0.1 时隐藏。
- 第 493 帧开始上下揭幕，每帧移动 50 个设计像素。第 506 帧开始显出真实登录表单，第 523 帧结束开场。没有单独 Logo 切换造成的位置跳动。揭幕光带直接使用原 `lightFader`，没有重画。
- 登录就绪后不重播终端。保留双层反向噪声，每两帧改变位置，15–30 帧触发一轮扰动。取消正弦匀速漂移。战局加载才循环终端节奏，中央 Logo 和真实进度始终可见。
- `objects/fader` 保存新增参考源码。对应版本、时间点和素材 SHA-256 在 `source-manifest.json`。隐藏计时、跳过、减少动画和自动登录等待仍由原生命周期逻辑管理。
