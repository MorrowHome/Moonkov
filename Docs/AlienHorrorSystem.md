## 追猎与压迫

- 侧翼目标按个体选择稳定方向，避免所有怪排成直线。遇阻 1.2 秒后短暂退回直接追踪；运动仍由原接地/跨面碰撞负责。
- 窥行者使用目标的服务端视线判断注视，默认停顿 1.4 秒，之后持续逼近；不能一直盯住就永久冻结。遮挡后只沿最后目击位置搜索。
- 远程喷吐者近身时会退让，攻击冷却期间保留射距；已锁定的攻击仍完成原前摇、命中与收招。
- 两只 Boss 首次接敌、半血转阶段各有一次 1.8 秒威吓，期间不造成伤害。转阶段等待已承诺的攻击结束，不会中途缩短前摇。狂暴阶段至少保留 1.15 秒的实体攻击前摇和 0.9 秒收招。
- Boss 移动速度使用世界米/秒，不随四倍体型暴涨；转身、肢体频率和脚步间隔降低。精英与 Boss 有更低沉的原录音音高，窥行追猎时停止闲叫，减少连续吵闹。

## 正式接入与预算

原 `Boss` 标志保留兼容性；`ThreatTier`、`Approach`、`DisplayName`、`EncounterHint` 提供明确分层和中文调参说明。战报使用各自名称，既有异形肉、专属器官与 Boss 核心掉落链沿用原服务端实现。

`AlienEncounterSettings.MaximumBosses` 默认 1，同一时刻只允许一个活 Boss；同一种 Boss 的多个刷新槽作为候选，每局合计只生成一次。巨型出生检查覆盖完整躯干高度、展开根系支撑及外缘可见性，避免本体躲在小石头后却让巨大触肢当面出现。攻击范围与可见触肢跨度匹配，重砸/根刺仍为局部落点。

Boss 液体采用 0.085 模型单位采样间距，维持原解算与体积分辨率；单只 Profile 最多一个近距液体名额、22 米切换范围。远处继续显示真实体型与甲冠。服务端不创建甲冠、材质或 GPU 资源。

## 验证

- Unity 编译；定向服务端检查覆盖两只巨型 Boss 的实际移动、无伤威吓、一次性狂暴、完整净空拒绝、零 Renderer 分配，以及凝视停步上限、侧绕、远程退让、10 度斜坡移动。
- 正式地图 23 个槽位中，两种 Boss 的四个候选槽均找到符合完整净空和外缘支撑要求的位置；同种 Boss 的多个候选共享一次生成预算。既有 Boss 墙体阻挡、攻击后换位和黏液命中/闪避/墙体阻挡检查通过。
- 真实 GPU 液体体型预览。原 `Umbra08Fluid.compute` 的整数转换与取模性能警告仍存在；预览命令因此可能返回警告状态，不能等同于新增 C# 编译错误。
- 肢王 / 葬根 / 长颈监视者的实际 GPU 粒子数分别为 5160 / 5558 / 3571，三者采样非有限数均为 0；这属于短时定向检查，不是持续负载帧率测试。
- 报告位于 `Library/BuildValidation/AlienIntegration/horror-*.txt`。检查入口为 `Tools → Moonkov → Aliens → Check horror tiers and giant bosses`，正式地图落点另有 `Check giant boss formal map placement`。

这些证据不替代正式地图 Play、Host/第二客户端、完整路线、音频听感、目标设备帧率与玩家恐怖感验收。巨型 Boss 需要宽阔区域；现有 NavMesh 不按其体型重建，不保证通过狭窄建筑或任意路径。所有联机端应使用相同版本。
