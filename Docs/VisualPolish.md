# 视觉质感精修

2026-10-13。范围为正式 Apollo12 环境接入、月面画面层次、局内交互 HUD 与武器落点表现。未调整伤害、弹道、搜刮判定或网络协议。

## 正式环境

`Apollo12GameScene` 已引用 Full v02 的 `Apollo12MC00Candidate.prefab`。保留原地形、8 个出生点、12 个物资点、撤离点与服务端时钟；MC00 物资索引 4–7 的原坐标通过地板高度和站立空间检查。继续使用 `Apollo12LaptopPipeline` 的 350 m 室外阴影，未应用候选预览的 30 m 室内配置。按钮资产已进入正式环境，联网开关操作尚未实现。详见 [地图接入](MoonNetworkMap.md)。

## 画面层次与调色

共享 `MoonRenderer` 加入低强度屏幕空间环境遮蔽，强调墙角、设备底部与物件接触：强度 0.65、半径 0.35、降采样开启，作用衰减距离 35 m。该效果增加屏幕空间渲染成本，不能根据设置宣称帧率改善。

`MoonSpacePostProcessing` 使用轻微冷阴影、暖高光分离，对比度 10、饱和度 -5；Bloom 强度收至 0.28、散射 0.55，并加 0.12 的轻暗角。正式环境启用现有曝光适应，上限收至 1.5 EV；它使用几何遮挡估计，不是 GPU 亮度直方图。Moon、Apollo12Laptop 和 MC00Interior 管线启用 HDR 调色；这些共享资产的引用场景都会受影响。

## 原灯、反射和室内阴影成本

最终配置没有添加补光灯。L22 控制室和 G03 服务间共九盏原灯：四盏顶灯由 19.5 调至 24.375，五盏设备灯由 2/4/5.2/5.2/2 调至 3/6/7.8/7.8/3，保持原灯位、角度、范围与阴影档位。调整保存在正式场景覆盖中；建筑源 Prefab 可继续替换。入口为 `Tools → Moon Environment → Apollo 12 → Apply interior lighting`，固定值保证重复执行不叠加增亮。

`InteriorLightingRig` 最终只创建两处 128px HDR、盒投影反射探针。相机接近时串行分帧捕获；灯具电源变化立即隐藏旧反射并重新捕获，平常不每帧重渲染。PC Quality 启用实时反射支持。先前四盏向上补光的实验已移除，旧实验截图不能代表最终方案。

正式 Pipeline 关闭 GRD。`MoonSceneLighting.adaptInteriorShadows` 开启后使用运行时管线副本，源资产保持 350m 阴影距离。`MoonInteriorShadowRange` 每 0.25 秒最多六条射线：头顶 12m 内有遮挡，且视口中心、四角均在 60m 内命中时，距离收至 `max(40m, 最远命中+10m)`，不超过 75m 或源设置；收距用 0.5 秒，视野开放后在下次检测立即扩回源距离。这是有界视野采样，不是对整个建筑封闭性的证明；小窗、快速转向仍需实际游玩观察。禁用选项恢复原距离，退出场景还原旧管线并释放副本。

同一控制室机位、2560×1440 Game View、内部 0.75、冻结玩法时间的编辑器短采样，每阶段 180 帧：

| 配置 | 中位帧耗时 | P95 |
| --- | ---: | ---: |
| GRD 开启，350m | 30.394 ms | 41.415 ms |
| GRD 关闭，350m | 29.722 ms | 35.877 ms |
| GRD 关闭，手动 40m 对照 | 19.872 ms | 32.263 ms |

## 星空与地球

原 Apollo12 天空材质的星图强度 0.025、日间可见度 0，导致日间星星完全隐藏。正式材质改为 0.25 / 0.5，强化亮星、压低弥散底色，并限制 HDR 峰值；shader 保留 mip，使用固定子像素采样和经度接缝梯度修正，不添加随机闪烁。地球新增 `_EarthAngleScale=4`，展示角直径从 1.9° 改为 7.6°；这是游戏美术放大，天文方位、相位和自转不变。通过 `MoonSpaceSkyTools.ApplyReadableGameSky` 可重新应用到指定天空材质。

## 工业物资箱

12 个物资箱替换为倒角外壳、护角、锁扣、把手和细状态灯；所有箱共享两个 Mesh、六个材质及一张 128px 程序漆面纹理，每箱两个 Renderer。位置、编号、碰撞和服务端搜刮状态保持原逻辑，耗尽只切换状态灯材质；资源随地图销毁。实际室外近景：`Library/BuildValidation/revision-cache-lit.png`。

## 交互与落点

- 容器提示改为独立 `E` 键帽、物资/空箱状态与距离，使用短淡入位移和克制的警示色。仍沿用原有 3 m 最近容器选择，不是新增瞄准选择或穿墙交互。
- 月尘、合金、电池的正增量由服务端 RaidSnapshot 确认后显示回执；打开背包时排队，关闭后显示 3.2 秒。首次同步、再次出战和结算不会当成新拾取，暂不覆盖其他装备类型。
- 撤离信标增加由服务端剩余时间驱动的细进度条。以上均在正式 Raid HUD 生效，独立 MC00/蜘蛛预览不会自动显示。
- 岩面使用带切角的灰色岩屑和短时低重力月尘；金属火花从暖白亮芯衰减为橙色，补充 MC00 铝材识别；狙击保留短蓝白接触闪光。沿用 16 个池化落点槽，每槽两层且总预算仍为 256 粒子，不在射击时创建材质或对象。两层透明绘制的实际开销尚未测量，详见 [武器反馈](HaloWeaponFeedback.md)。

## 验证边界

本轮 Unity 已完成脚本导入编译，落点 Shader 检查无编译错误。正式主菜单启动独立临时存档的离线对局，确认运行环境为 `Apollo12MC00Candidate`、管线为 `Apollo12LaptopPipeline`，服务端时钟已同步。临时档放在 `Library/BuildValidation/VisualPolishProfile-*`，未使用玩家原存档。

实际 Game View 检查了室外第一人称，以及 MC00 物资点 06 附近显示的中文容器卡片、E 键帽、内容状态和 1.1 m 距离。验证角色通过临时传送定位，未据此声称全程行走通过。两种落点以独立运行时组件直接调用 `Present`，冻结约 0.07 秒后检查：共 21 个岩屑/月尘/金属火花粒子可见，非实弹命中或网络确认测试。截图为 `Library/BuildValidation/visual-formal-exterior.png`、`visual-formal-mc00.png` 和 `visual-impact-probe.png`。

后续重进正式离线场景确认运行时管线副本、两个探针捕获完成且队列为空，检查了无新增补光的控制室画面和实际星空；天空 shader 无诊断。固定临时相机用于构图，未据此声称实际行走通过。最终控制室前后图为 `revision-control-before.png` / `revision-control-after.png`，天空为 `revision-sky.png`。更早的 `revision-service-after.png` 等补光实验图不属于最终配置证据。

撤离进度条的早期运行检查期间 Play 被外部流程停止，本轮未完成该项，也未实测物资回执。编辑器另有 NetCode/调试连接等日志，不能据此声称 Console 零错误。新增时钟组件时暴露的静态 `Reset` 与 Unity 编辑器消息重名已改为 `ResetPresentation`。

用户报告的直角白线与重叠面闪烁尚未定位到具体构件，未宣称修复。当前 STP 已包含时域抗锯齿；FSR 的 0.92 锐化参数不控制 STP，不能将改它作为修复。MC00 存在亚毫米倒角和高光材质，这是细边闪烁的候选原因；源数据没有查到同网格、同矩阵的完整重复实例，仍不能排除局部共面。应根据具体位置做局部几何/材质修复，不全局改 ZTest 或用深度偏移遮盖。

尚不能据此宣称多人对战、独立构建、整图导航或 4060 Laptop 1440p 稳定 60 FPS 已通过。最终画面和操作手感仍以正式场景实际游玩为准。
