# 通用光环进度

用户最终选择 P2，以头顶正式光环的填充作为通用动作进度。`approved-reference.png` 是选型图。当前实现直接引用正式光环精灵，不使用选型图截图作为游戏素材。

## 显示

复用 `Assets/DollSinger/Art/Rifle` 的四张精灵。六片外环、六段中环、三段内弧、三十格保持静止。通过角度遮罩从顶部顺时针填充。没有旋转尾巴、发光粒子、底板或设备外壳。中心保留现有准星。

`HaloProgressRing` 负责图形，`RaidTimedActionView` 负责短动作名称和时间，`RaidHUD.Progress` 负责选择当前动作。治疗和搜索优先，其次为道具、手动设备、撤离和充能。同一时刻只展示一套。资源量、近战瞬间动作与机器自动生产不伪装成玩家操作进度。

回执仍来自原有权威状态。客户端计时不能发放收益。计时结束后继续保持动作名称，隐藏零秒文字，最多填到 97%，直到收到实际结果。取消和失败不显示全满光环。键盘 X 沿用原取消行为，装备页内保留小型可点击取消入口。

## 成本与边界

四组精灵共享纹理。构造时生成固定布局，每次重绘复用顶点和索引缓冲区。没有逐帧加载纹理、查找场景对象或重建层级。没有新增网络或存档字段。

紧致精灵的纹理裁切必须保留原枢轴和像素比例。不能将 textureRect 直接映射到完整 sprite.bounds，否则方格会被拉长，内弧会重叠。

原生预览入口为 `Tools/Moonkov/Review Timed Actions`。它使用真实 UI 控件、正式准星纹理和样例进度，不能作为实际战局证据。

## 验证

Unity 编译通过。24 项显示与交互检查、40 项充能反馈、75 项原动作规则、43 项实际服务端处理器回归通过。已看 25%、50%、75% 原生渲染，明暗背景下方向和完整轮廓正确。未进入真实战局、联机或 Player 构建。原生对照图在忽略目录 `LocalData/HaloProgress/native-progress.jpg`。
