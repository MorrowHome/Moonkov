# 环境影调与头罩光学修正

2026-10-22。状态：滤镜范围、默认颜色与头罩外围玻璃已完成，并通过本轮静态检查；整体 AAA 资产质量尚未达到。源码基线为 `a14aeff7`，本轮开始只有两份用户字体存在未提交修改，已独立备份至 `Library/BuildValidation/EnvironmentOptics-20261022/`。

用户指出：原滤镜只想用于地形与建筑，但人物、任务效果和灯光也出现异常变色；希望利用太空服头罩的视觉语言，同时提高画面的特色与真实细腻度。

## 本轮方向

- 环境以银灰月面工业材料为基底，保留材质本色、PBR 高光、粗糙度差异、连续明暗和局部冷暖照明。蓝色用于能量设备与指示，不将不同色相的实际灯光统一替换成钴蓝。
- 地形和静态建筑有明确的环境处理范围。角色、武器、掉落物、任务标记、粒子、UI 与预览相机保持其原有颜色与语义；处理透明效果时考虑实际合成阶段，不能仅凭最终深度就声称隔离成功。
- 角色沿用原有二次元材质和配色。环境细腻度先恢复可读的材质与照明层次，再根据实际画面作有限修正；不在本轮重建地形、建筑或渲染管线。
- 头罩光学只作用于装备真实头罩的拥有者第一人称相机，保持瞄准中心通透，以克制的玻璃边缘、微弱反射和密封质感呈现。第三人称继续显示头罩外观。原有护盾反馈与暗视不改变玩法，不新增视觉模式快捷键。

## 已知证据与待核实项

源码 `MoonSilverPrint` 在渲染后段处理已打光的画面，当前人物保护依赖登记；`SilverPrint.shader` 的 `Accent` 同时把冷色与暖黄识别为钴蓝点色候选。这与用户反馈相符，仍须通过本轮同机位实际渲染确认修正结果。

项目旧对比图能看到高对比黑白块面、暗部损失和月壤纹理强调；这些历史图只用于了解美术基线，不作为本轮验证证据。新参数必须在正式场景实际入口生效，不能只修改被序列化值覆盖的 C# 默认字段。

## 执行与验收

仅一个执行对话持有编辑器操作权，任何时候最多一个 Unity Editor，已有时复用。本轮仅允许必要的 EditMode 静态相机渲染，不进入 Play，不启动游戏客户端、联机验收、Blender 或光照／导航烘焙；控制内存并及时释放临时资源。Mac 仅任务期间临时保活，结束释放，无登录自启。

必要证据为正式环境外景与彩灯室内两组同机位前后图；分辨率、FOV、灯光与机位一致，并检查真实角色／任务效果的颜色和头罩适用相机范围。少量关键图足够后停止扩展。记录 C# 与 Shader 导入、Console 基线、实际绘制范围及清理状态；截图不证明真实游戏流程或 GPU 性能。

不得混入用户字体，不修改库存、AI、近战、网络规则、地图 UI 或无关资产。完成必要验证后由协调方单独审查、commit 并 push；未验证或仍受资产限制的部分明确记录，不将一次调色描述成整体 3A 资产升级。
