# 第一章教学版接入记录

2026-10-25。当前实施范围只包含第一章“静默着陆”。用户已确认八章故事方向，随后要求先完成第一章，用于教学和背景引入。其余章节、证据匣、返航与地球结局保留为后续策划。

## 玩家流程

在单人模式的任务页查看公司简报与沈禾通讯，整理光环和电池，再按正常流程出战。第一章默认追踪，可手动取消。

1. 报到：前往研究站入口，在现有入口设备登记清理队身份。
2. 备用线路：看故障说明，隔离配电 A 烧损支路，再恢复配电 B。
3. 第一份样本：启动取样机，等待真实的 45 秒切割，从输出槽取走月核碎片，成功撤离。

当前步骤、地点、楼层关系和必要教学提示显示在局内 HUD。J 打开任务与通讯记录；近距设备仍使用现有 F/手柄操作，配电 A 保留真实离散选项。节点变化时出现一次短通讯，切换追踪不重复播放。

取样与拾取不等于入库。成功撤离并确认保存后，显示第一章完成，以及“实验场信号为什么还在运行”的背景疑问。本版不开放第二章。

## 建筑未定稿的处理

本轮没有修改建筑网格、场景坐标或正式场景文件。任务通过 `entry`、`power_a`、`power_b`、`sampler` 和 `ship.return` 语义锚点连接已有设施。

坐标由 `RaidMissionSite` 与地图撤离点提供。更换建筑时，在作者化配置中重绑入口和设备，重新核对可达路线、交互视线和时间。存档保存任务 ID 与完成事实，不保存建筑坐标，也不依赖固定楼层编号。

第一章在本机运行时派生月核模板，追加入口登记目标，并保障该流程出现；供电、长按打断、自动切割、输出槽、真实库存和撤离继续使用原系统。联网和 LAN 不进入这条教学战役。

## 进度与失败

- 无需接取。追踪只控制显示，不授予操作权限或奖励资格。
- 三个任务可在一次出战连续完成，同次撤离原子保存，不要求为了交任务往返三次。
- 已保存的登记和完整供电阶段，在下次教学出战恢复到真实设备状态。
- 未提交的切割进度不跨局保留。死亡、超时和普通退出沿用既有物品损失与保护规则。
- 拾取后丢弃样本，局内目标重新要求真实持有；结算再次核对本次冻结库存与物品来源。
- 旧库存碎片和旧首次成长记录不自动完成第一章。普通首次回收奖励继续使用原回执，不叠发章节奖金。
- 追踪选择跨局保存，结算不会拿旧的局内快照覆盖最新显示偏好。
