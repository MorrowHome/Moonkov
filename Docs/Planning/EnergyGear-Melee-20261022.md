# 能量护具、生命维持头罩与近战契约

2026-10-22，实施中。用户已确认关键玩法，其余技术、美术、资源许可与初始数值由副程序决定，不因用户休息等待常规细节。

## 用户确认的范围

- 独立能量护盾发生器，占护具槽；受击消耗护盾，脱战耗电缓慢恢复，也可用电池补能。不采用传统防弹衣和战术头盔作为本轮战斗护具。
- 能量剑、匕首为可装备近战物品；拳头为无武器后备。左键轻击，右键重击；第一、第三人称均有对应动作。
- 生命维持装备收敛为头部能量罩与实体颈环，不做全身太空服。保留角色脸和头发，负责密封与供氧，与战斗护盾分离。
- 沿用月面科幻美术；可寻找许可适当的公开动作资源，找不到则独立制作。未经许可不导入外部资源，不采购素材。

## 实现与质量要求

战斗护盾应在受击点产生可辨识的波纹、表面闪光和方向反馈，耗尽有破盾提示，恢复有适度视觉变化。不能以全屏蓝色蒙版代替能量体，也不能持续过曝、遮住准星或影响对手识别。权威伤害先消耗有效护盾，超额伤害继续进入原身体系统；缺氧、饥渴、内部毒性等生理伤害不被护盾抵消。电池是真实库存能量，不能换装、重连或重新拾取免费补满。

生命维持头罩采用通透外壳、薄发光边缘与颈环展开效果，第三人称可观察穿戴差异；拥有者第一人称须避免折射、反光和边缘遮住视线。密封、供氧和耗材复用现有 RaidOxygen、气氛及氧气罐系统，不另建一套氧气数值。旧存档中的装备继续可读，不破坏既有气闸和缺氧规则。

近战须有前摇、有效攻击窗口和恢复，不允许按键即远距离扣血。按真实武器范围扫掠并检查墙体、楼层与友军；同次攻击对同一目标最多一次伤害。受击反馈、武器轨迹和动画时机一致，换武器、倒地、死亡、菜单与耗时操作正确取消或阻止攻击。右键重击仅在近战激活时接管，枪械仍按原输入瞄准。拳头不创建虚构库存物品。

三类近战各有可辨识的待机、举起、轻击组合、重击和收势；复用当前完整双臂 Blender 烘焙经验，独立资源不覆盖已认可枪械动作。第一人称实际看得到手和武器，第三人称动作与攻击一致，不能只有摄像机抖动或单个固定姿态。

新增装备与近战必须从正式商店或搜刮获得，能放入库存、装备、丢弃、死亡掉落、撤离返还并保存；装备与能量变化不因界面刷新重复应用。必要时扩展现有库存和快捷栏，维持 JUI 风格及旧存档兼容。AI 与真人遵循同一防护和伤害规则。

## 执行顺序

先完成并验证单人赏金速战骨架，再接入共享装备、伤害与动作，避免并发改写关键文件。动作源制作与护盾视觉研究可独立进行。Shared 库存、PlayerInput、预测状态、移动与表现接入点先明确唯一文件所有者，再允许修改。

验证包含规则、库存能量与持久化、实际第一/第三人称动作和护盾画面、正式地图命中及遮挡；纯断言与真实画面分别记录。只用当前一个 Editor，不开多个玩家客户端，不连接用户当前关闭的 Windows 后端。两份已有字体修改保持原样，不纳入任务提交。每阶段完成必要验证后仅提交相关文件并 push 当前 develop。
