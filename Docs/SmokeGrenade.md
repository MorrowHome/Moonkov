# 烟雾弹

2026-10-23，接入现有 Tactical Items 服务端道具链路。

- 商店购买“烟雾弹”（16 月尘），战利品表也可抽到。放入口袋或胸挂，绑定现有快捷栏后使用；沿用投掷预览和 1 秒使用动作。
- 物品代码 `smoke_grenade`，每格最多 3 枚。3 秒引信，半径上限 5 米、竖直半径 3 米；烟幕中心在落点上方 1.4 米，1.2 秒展开，总持续 20 秒，最后 3 秒渐隐。不伤害、不咳嗽、不灭火，与窒息弹分开。
- 服务端负责扣除、弹道、引信、烟幕时限和 AI 感知。客户端复用周期快照，迟到的快照按剩余时间恢复展开/消散阶段；切换地图、World 销毁及移除消息沿用原有清理。
- PMC 的多点视线与开火检查接入烟雾光学厚度；丢失视觉后复用最后位置、听觉与搜索逻辑。怪物只在感知阶段遮挡视觉，仍能听到枪声，沿用记忆搜索。已发动攻击的物理结算不受烟雾阻挡。
- 不创建烟雾 Collider、不改变导航、不阻挡声音和弹道。贴身短距离、薄边缘和烟幕上方仍有视线；多团烟幕的光学厚度累加。状态按服务端 World 和 PhysicsScene 隔离。
- URP 烟雾使用 32 步体积采样、流动噪声和柔和边缘，通过现有 Tactical 透明通道在 SilverPrint 后合成；深度纹理截断到前景表面，镜头进入烟幕仍能遮挡。无新依赖、无场景/渲染器资产改动。

## 验证

在现有 Unity 6000.5.10f1 Editor 内编译。`TacticalItemsAuthorityChecks.Run()` 包含真实 RPC 扣物品、引信变烟幕、穿烟/烟内/贴身/上方视线、PhysicsScene 隔离、物理射线与到期移除检查。`SmokeGrenadeChecks.Run()` 检查几何边界、展开/淡出和 Shader 支持；`Capture(path)` 使用临时预览场景检查烟外、烟内、前景遮挡、淡出及移除。

未进行联机验收、正式地图实战走图或 GPU 性能测量。

## 当前边界

这是基础体积烟幕，不是 CS2 体素流体模拟。烟幕不按房间/门窗填充，不做几何封闭空间裁剪：墙体会通过深度遮住其后烟雾，但烟雾范围可能延伸到墙体另一侧。AI 以保守的平滑体积判断，画面的细小噪声不传到服务端。未实现子弹开洞、爆炸吹散或 AI 主动投烟。多团重叠的透明采样成本需要在目标机器实测。
