# 装备放置与数字快捷栏修复

分支 `fix/raid-equipment-quickbar` 依赖 `fix/raid-inventory-pointer@7d4360a9`；搜刮三栏布局另在独立分支实现。

快捷栏原来要求拖起时的物品对象与当前库存对象完全相同；即使 ID、物品类型、版本一致，回包替换对象后也会拒绝。现在用 ID 解析当前快照，验证类型及可用位置；已移除、改型或不可用物品仍拒绝，不修改库存数量或服务器状态。

统一拖放、数字键和“选中物品后点击数字槽”的绑定入口。绑定是本地偏好操作，等待战斗／库存动作回包不再静默禁用它。无效物品仍提示须先穿戴武器、把消耗品移入衣兜或胸挂。移除搜刮上下文直接跳过装备槽的分支；槽位的展示与空容器入口由布局分支接入。

`RaidEquipmentBindingChecks.Run()` 覆盖快照替换、已移除／改型／不支持的物品和库存不变。真实对局操作及联机未作为此检查的证据。
