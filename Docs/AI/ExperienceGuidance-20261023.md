# 出战与局内决策反馈 — 2026-10-23

目标：提示必须对应玩家当前可以完成的行动，结束状态不能继续承诺回收收益。保留现有 UI Toolkit 与地图、经济、存档和网络规则。

## 设施任务引导

- 失效和结束优先于携带状态；不会被“已携带”“立即返回”覆盖。短通知也不能覆盖终态。
- 结束后隐藏任务方向标记、距离与进度条；空输出槽且未携带产物时不再指向空设备。取走最后一件产物的玩家仍获得撤离引导。
- 现有快照变化立即刷新；补充每 0.25 秒的本地呈现刷新，让库存变化、移动距离和短通知结束不依赖下一份任务快照。只读取已同步状态，不推算或裁决任务期限。
- 日常资源风险文字用辅助色；开放窗口最后 60 秒强调警告色和字重。结束卡片使用中性边线。
