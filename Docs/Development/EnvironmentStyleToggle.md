# 开发用环境风格对比

编辑器 Play 或 Development Build 中，进入正常角色操作后按 **Ctrl+L**（左右 Ctrl 均可）：临时反转场景保存的原始照明／风格化选择，再按恢复。正式 Theophilus 默认风格化，因此第一次按下查看原始照明。按住不反复切换；暂停、背包、鼠标未捕获或灯光调节面板打开时不响应。

组合键在原有 L 灯光手势之前消费，只改变拥有者本地画面，不开关灯、不打开长按灯光面板、不发送网络命令。角色销毁时解除绑定。

每次启动从场景保存值开始，Editor、Development 和 Release 的初始模式一致。角色重生保留本次会话的临时对照状态；退出不写入场景、材质、PlayerPrefs 或存档。强度为0或组件禁用时仍不处理画面。

普通发行构建不包含组合键或开发开关。Inspector 的 **原始照明 / 跳过风格化** 始终是当前场景的基础设置，Play 中组合键只临时反转它；原始照明模式直接跳过整个风格化 Pass 链。它不撤销已经应用到白墙材质的釉面高光。

开关不改变环境作用范围、角色／透明效果／UI的隔离，也不改变正式场景灯光和烘焙资源。具体参数见 [Theophilus 黑白银白与钴蓝风格](../MoonSilverPrint.md)。

历史验证边界：此前 Edit Mode 键盘模拟未通过 Ctrl+L 按下沿检查，不能作为真实键盘交互通过的证据；本轮模式解析调整也不应被当成独立客户端或联机验收。
