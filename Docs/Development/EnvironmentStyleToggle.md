# 开发用环境风格对比

正式 Theophilus 使用写实基线：`MoonSilverPrint` 组件禁用，`faithfulLighting=true`、`intensity=0`、`previewInSceneView=false`。旧滤镜保留为实验功能，默认不参与渲染。

Editor Play／Development Build 中按 **F1** 临时开启风格化，再按 F1 恢复场景原设置；不再使用 Ctrl+L。组件禁用或保存强度为 0 时，F1 会在本次运行内临时启用配置了材质的组件，并使用强度 1 预览，不修改保存的强度、材质或场景。恢复时只重新停用本开关临时启用的组件，不停用原本已启用的组件。找不到有效材质时输出明确提示。

按住不重复切换；暂停、背包或灯光调节面板打开时不响应。游戏已获得焦点、鼠标未捕获时，F1 会同时重新捕获鼠标并切换预览，避免首次按键被旧的捕获动作吞掉。普通 L 的头灯手势继续保留。开关只影响拥有者本地画面，不发送网络命令；角色销毁时解除输入绑定。

每次启动重置临时预览状态；同次会话内角色重生保留该状态。开关不写入场景、材质、PlayerPrefs 或存档。普通发行构建不包含此开发快捷键，F1 原有的鼠标捕获行为保留。

原材质、曝光、Bloom 和反射配置见 [Theophilus 写实环境基线](../MoonSilverPrint.md)。本次不修改模型、贴图、烘焙资源、自动曝光或已有打包和联机修复。
