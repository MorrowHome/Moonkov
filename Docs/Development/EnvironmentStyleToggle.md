# 开发用环境风格对比

功能分支：`feat/dev-style-toggle`；日常基线与集成目标：develop。main 由用户手动管理。

编辑器 Play 或勾选 Development Build 的游戏中，先让游戏窗口获得焦点并进入正常角色操作，再按 **Ctrl+L**（左右 Ctrl 均可）：第一次切换为风格化银盐，第二次返回保真照明。按住不会反复切换。暂停、背包等阻断操作的界面、鼠标未捕获或正在调整灯光时不响应。

L 原本负责角色 Halo 灯光，因此开发组合键在灯光手势之前消费，只改变本地画面，不触发开关灯、灯光长按调整或网络命令。只为本地拥有角色的输入绑定此功能；销毁角色时解除绑定。

每次进入 Play/启动开发版都从保真照明开始，角色重生时保留本次运行的选择；退出后不写入场景、材质、PlayerPrefs 或存档。不修改现有银盐参数：风格化使用 `Theophilus Silver Print` 上已经调好的参数；总强度为 0 或组件禁用时仍不处理画面。原有材质作用范围、透明效果绘制顺序、Bloom、角色和 UI 的处理沿用现有实现。

常规发行构建不包含组合键、回调或开发开关状态，继续使用场景正常配置。编辑模式下 Inspector 的保真/银盐预设及 Scene 预览保持原有行为；Play 中该快捷键只临时覆盖保真/风格化模式。

此开关用于比较与继续调试现有风格化效果，不代表已经重新验收角色全部材质、灯色或任意机位的视觉表现。

验证：当前 Unity Editor 已完成全工程 C# 重编译，无编译错误；改动未修改场景、材质或 Input Actions 资产。Edit Mode 模拟键盘检查未通过 Ctrl+L 的按下沿检查，不作为快捷键通过证据；实际游戏窗口内按键、灯光手势共存和风格切换画面仍需局内确认。本次没有进入 Play、创建网络 World、运行联机或构建。
