# 开发用环境风格对比

正式 Theophilus 使用写实基线：`MoonSilverPrint` 组件禁用，`faithfulLighting=true`、`intensity=0`、`previewInSceneView=false`。旧滤镜保留为实验功能，默认不参与渲染。

Editor Play／Development Build 中，Ctrl+L（左右 Ctrl 均可）的输入绑定继续保留。没有已启用、强度大于0且材质有效的效果时，组合键被消费但不切换状态、不输出旧风格提示；它不会落入普通 L 的头灯开关或长按调节手势。

显式启用有效实验效果后，Ctrl+L 才临时反转场景保存的保真／风格化选择，再按恢复。按住不重复切换；暂停、背包、鼠标未捕获或灯光调节面板打开时不响应。开关只影响拥有者本地画面，不发送网络命令；角色销毁时解除输入绑定。

每次启动重置临时比较状态；同次会话内角色重生保留该状态。开关不写入场景、材质、PlayerPrefs 或存档。普通发行构建不包含此开发组合键。

原材质、曝光、Bloom 和反射配置见 [Theophilus 写实环境基线](../MoonSilverPrint.md)。本次不修改模型、贴图、烘焙资源、自动曝光或已有打包和联机修复。

## 验证边界

本轮不声称通过独立 Player、联机或最终画质验收。代码检查不能替代实际键盘交互；此前 Edit Mode 键盘模拟未通过 Ctrl+L 按下沿检查，也不能作为真实交互通过的证据。
