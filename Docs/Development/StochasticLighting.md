# 随机稀疏着色实验

2026-10-27。目标是少算一部分渲染，并保留整片表面的颗粒。不是叠加胶片噪点，也不是 Cycles 路径追踪。

## 工作方式

- 在片元入口随机保留 65% 的 2×2 像素组。跳过的组直接写黑色，仍写入正常深度，不露出后方物体。
- 保留的组才读取材质贴图并计算 PBR 光照。在线性颜色空间乘以保留概率的倒数，补偿平均亮度。
- 随机图案固定在屏幕上。静止时不逐帧闪烁；移动时仍可能有网格感。没有时域累积或降噪。
- 按 2×2 像素组选择，保证组内纹理导数可用。粗颗粒设定使用整数倍大小。
- 软阴影从常规的 4、9 或 16 次比较采样，改成 1 或 2 次随机比较采样。仍有硬件比较过滤。随机方形核与原帐篷核的边缘外观不同。
- 硬阴影不随机偏移。保留阴影强度、远处淡出、烘焙阴影混合和点光源面选择。屏幕空间主光阴影回退原路径。

## 接入范围与开关

在要试验的 Camera 上添加 `MoonStochasticLighting`。关闭组件即回到原效果。默认保留概率为 0.65，阴影采样为 1 次。概率设为 1 时，只试验低采样软阴影。

当前接入 `MoonEnvironment/Industrial Dust`、`Moon/R29 Industrial Display`、`Moon/R29 Local Ground Display`。它们覆盖整个表面的着色，不局限于阴影边缘。其他材质、角色、天空和 UI 尚未接入。这是环境材质试验，不代表正式地图已全画面覆盖。正式场景和角色预制体没有添加该组件，默认效果不变。

组件只在所属相机渲染期间设置全局关键字和参数，结束后恢复。未修改 URP 包，没有额外全屏 Pass。三个环境 Shader 的前向着色变体增加一倍；构建体积与编译时间仍需 Player 验证。

## 预览和检查

运行 `Tools / Moon Environment / Stochastic Lighting / Render comparison`。使用临时预览场景，不进入 Play，不保存正式场景。输出在被忽略的 `LocalData/StochasticLighting`。

检查覆盖：

- 三种环境 Shader 在 Metal 上实际渲染。检查 Shader 编译错误。
- 平行光、聚光灯、点光源的原效果、低采样阴影、稀疏着色截图。
- 固定相机连续两帧逐字节一致。另输出平移 0.08 米后的截图；这不代替连续移动观感验收。
- 保留概率为 1 时，硬阴影与无阴影的开关前后图像逐字节一致。另输出无阴影的稀疏着色图，检查颗粒覆盖受光表面。
- 关闭预览后，相机关键字、全局参数和原场景脏状态恢复。

2026-10-27，Unity 6000.5.10f1、URP 17.5、Apple M5。1600×1000，无后处理。临时复制当前 Pipeline，主阴影图为 1024、单级联、阴影距离 20 米。每种模式先预热，按交错顺序测四个区块，每区块 32 次渲染。每块末尾同步读回，包含 CPU 提交与 GPU 完成。

最后一轮各区块耗时的中位数，单位为毫秒/次：

| 灯光 | 原软阴影 | 仅单采样阴影 | 单采样阴影与 65% 稀疏着色 |
| --- | ---: | ---: | ---: |
| 平行光 | 1.090 | 0.911 | 0.935 |
| 聚光灯 | 1.091 | 0.943 | 0.943 |
| 点光源 | 1.141 | 0.990 | 1.060 |

本轮组合方案比原效果少约 7%～14% 的渲染耗时。收益主要来自阴影降采样。稀疏着色本身没有测出额外收益，部分配置反而略慢。不能把跳过 35% 像素组称为 GPU 快了 35%；GPU 的并行执行与分支会影响结果。

聚光灯截图的平均线性亮度：原效果 0.051679，单采样阴影 0.051693，组合方案 0.051711。此检查不保证高光经过曝光、裁切和色调映射后仍保持一致。

这是隔离编辑器的吞吐测量，不是独立 GPU 计时、正式地图帧率或目标设备验收。尚未在 Windows、Player、完整地图、多角色或连续移动中验收。没有缩小阴影图来计算“优化前后”的差值；每组比较使用相同配置。
