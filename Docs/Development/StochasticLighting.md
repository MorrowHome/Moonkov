# 随机灯光采样实验

2026-10-27。目标是减少一部分光照采样，并让受光表面保留细颗粒。不是胶片噪点后处理，也不是 Cycles 路径追踪。

## 当前实现

- 每个像素独立决定是否采样某盏灯。默认每盏灯的保留概率为 0.85。使用整数散列，避免规则斜纹。
- 未选中的灯不取阴影和灯光 Cookie。选中的灯将直接光贡献除以保留概率，补偿期望亮度。
- 所有表面像素都保留材质贴图、间接光、发光和雾。不同灯分别采样，不把整块像素直接涂黑。只有单一光源且没有间接光时，未采到光的像素仍可能接近黑色。
- 默认颗粒为单像素。随机图案固定在屏幕上，静止时不逐帧闪烁。没有时域累积或降噪；移动观感仍需试玩。
- 软阴影从常规 4、9 或 16 次比较采样，改成 1 或 2 次随机比较采样。仍有硬件比较过滤。随机方形核和原帐篷核的边缘外观不同。
- 保留阴影强度、远处淡出、烘焙阴影混合和点光源面选择。屏幕空间主光阴影使用原路径。硬阴影不随机偏移。
- 减法混合烘焙模式的主光不参与随机选择，避免破坏间接光修正。启用 Cookie 变体时，主光也保留确定性计算，避免隐式纹理导数失效；额外灯的 Cookie 使用显式 LOD。

此前的 2×2 稀疏表面着色已撤下。那种方法会直接留下黑色网点，颗粒太粗，也不符合 Cycles 的光照噪点特征。不要恢复它来声称性能优化。

## 开关和范围

在试验 Camera 上添加 `MoonStochasticLighting`。关闭组件即回到原效果。默认阴影采样为 1 次，灯光采样概率为 0.85。概率设为 1 时，只试验低采样软阴影。原字段 `shadingProbability` 已用 `FormerlySerializedAs` 迁移到灯光采样概率。

当前接入 `MoonEnvironment/Industrial Dust`、`Moon/R29 Industrial Display`、`Moon/R29 Local Ground Display`。颗粒覆盖这些材质的受光表面，不局限于阴影边缘。其他材质、角色、天空和 UI 尚未接入。正式场景和角色预制体默认未添加组件，不能称为正式地图已全画面覆盖。

组件只在所属相机渲染期间设置全局关键字和参数，结束后恢复。没有修改 URP 包，也没有新增全屏 Pass。三个环境 Shader 的前向着色变体增加一倍；构建体积和编译时间仍需 Player 验证。

## 验证与性能

运行 `Tools / Moon Environment / Stochastic Lighting / Render comparison`。使用临时预览场景，不进入 Play，不保存正式场景。输出在忽略目录 `LocalData/StochasticLighting`。当前全表面图后缀为 `sampled`；旧 `sparse` 图已经失效。

检查通过：

- 三种环境 Shader 在 Metal 上实际渲染，没有 Shader 编译错误。
- 平行光、聚光灯和点光源的原效果、低采样阴影、单像素灯光采样对照。
- 固定相机连续两帧逐字节一致。另输出平移 0.08 米后的截图；不代替连续移动验收。
- 灯光概率为 1 时，硬阴影和无阴影的开关前后最大差异为一个 8 位颜色步长，没有新增颗粒。不同 Shader 变体可能有末位舍入差异。
- 关闭预览后，关键字、全局参数和原场景脏状态恢复。

Unity 6000.5.10f1、URP 17.5、Apple M5，1600×1000，无后处理。临时复制当前 Pipeline，主阴影图 1024、单级联、阴影距离 20 米。每种模式预热，交错测四个区块，每块 32 次渲染。末尾同步读回，包含 CPU 提交和 GPU 完成。

最后一轮各区块中位数，单位为毫秒/次：

| 灯光 | 原软阴影 | 仅单采样阴影 | 单采样阴影与 85% 灯光采样 |
| --- | ---: | ---: | ---: |
| 平行光 | 1.091 | 0.859 | 0.933 |
| 聚光灯 | 1.083 | 0.929 | 0.977 |
| 点光源 | 1.202 | 1.054 | 1.110 |

本轮组合方案的渲染耗时减少约 8%～14%。主要收益来自阴影降采样；随机灯光选择相对仅单采样阴影增加了开销。不能把减少 15% 灯光样本称为 GPU 快了 15%。GPU 的并行执行和分支会影响结果。

这是隔离编辑器的渲染吞吐，不是独立 GPU 计时或正式地图 FPS。Windows、Player、完整地图、多角色和连续移动尚未验收。每组对照使用相同分辨率、阴影图、灯光、相机和几何。

## 与 Cycles 的差别

Cycles 的噪点来自光线路径的随机估计，包含间接反弹、材质和光源采样等因素。本试验只随机选择直接灯光，并减少阴影过滤采样。没有增加路径追踪、真实多次反弹或面积光采样。它能形成更细的光照颗粒，不能自动复现参考图的完整光照层次。
