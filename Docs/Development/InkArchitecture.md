# 黑白建筑材质试样

用户确认的方向是黑白建筑拼贴。画面用大片黑色留白、灰白体块和少量蓝紫色。纹理像局部擦印。不要使用满屏霓虹、彩色 Voronoi 或均匀噪点。

本次直接替换正式地图的预览材质。模型、位置和相机保持一致。没有将新风格设为正式游戏默认值。

## 入口

在空闲的编辑模式运行 `Tools / Moon Environment / Ink Architecture / Render formal map comparison`。

工具读取已保存的 `TheophilusGameScene.unity`，在隔离的 Preview Scene 中渲染。结果位于项目根目录的 `LocalData/InkStyleReview/`：

- `exterior-before.png` 和 `exterior-ink.png`：建筑外景。
- `passage-before.png` 和 `passage-ink.png`：通道近景。
- `report.json`：材质数量、画面明暗占比、异常和状态恢复结果。

不进入 Play。不保存正式场景。不改写源材质、灯光烘焙或当前渲染配置。临时材质和预览场景在结束或异常时释放。

## 材质规则

`InkArchitecture.shader` 是 URP 材质 Shader。它按几何法线生成大块明暗，使用固定美术光向。它不采样原 PBR 颜色、反射或烘焙照明。原烘焙资源保留，供原始外观使用。这也意味着试样没有证明手电、枪口光和动态阴影的表现。

表面分为纸白、墨黑、蓝紫和地面四类。颜色不随时间变化。磨损采用世界坐标纹理，并在远处衰减细颗粒。蓝紫只分配给少量标识类材质，不把所有灯具和安全栏杆染蓝。

当前分类根据源材质名称完成。这是审美试样，不是正式的美术标签系统。透明材质暂时保留透明队列和低透明度，不能据此认为所有玻璃表现已验收。

## 边界

材质可以统一色彩、压低杂乱细节。它不能产生参考图里的巨型弧面、倾斜构图和疏密关系。下一步应选择一个真实交战区域，调整大轮廓，再结合射击和移动判断可读性。

当前工具只处理静态源地图。角色、武器、特效、HUD、战斗可读性、运行时开销和 Player 构建需要独立验收。没有添加逐帧材质复制或全屏后处理。

PNG 应从 sRGB LDR 目标读取。直接把线性 HDR 目标读成 PNG 会让原始画面显得过暗。切换相机 HDR 状态后先完成一次预热渲染，再导出对比帧。

正式地图通过 `MoonSceneLighting` 在运行时切换 URP 配置。隔离预览要读取同一配置，并在结束后恢复主菜单的配置。源地图包含双面薄片，新材质必须保留双面绘制。

## 本轮验证

2026-11-01：C# 编译和实际使用的 Shader 渲染通过。外景与通道各完成同机位前后对比。3359 个渲染器使用 386 份临时材质，源材质和编辑器场景状态恢复检查通过。两张试样的有色像素分别约占 0.44% 和 0.26%。这只说明点缀色面积受到控制，不代表已达到参考图质量。
