# Blender 与 Unity 画面对照

2026-10-28。源文件为用户提供的 `Moonkov_WH01_HU01_LR06_SR01_L23_Removed_Components_CANDIDATE.blend`。只读检查，没有保存或改写源文件。

## 已确认的差别

- 源场景使用 Cycles。最大渲染采样为 64，视口最大采样为 1024。渲染和视口都关闭降噪。刚开始渲染时的颗粒来自低采样，最大采样值不代表截图实际已完成的采样数。
- 源显示变换为 AgX，Look 为 Medium High Contrast，曝光为 0。Unity LR06 原展示相机没有开启后处理，不能视为相同成像设置。
- 文件含 406 个灯光对象，其中 398 个是面积灯。该计数不等于当前镜头实际启用的灯数。Unity LR06 展示场景只有 31 个无阴影暖色代理灯和一个方向光。代理灯不是面积灯和间接光的等价转换。
- 源文件 481 个材质数据块中，有 287 个含噪声、Voronoi、凹凸或节点组。该计数不代表所有材质都在镜头内使用。现有全图展示仍有基础颜色近似，不能靠颗粒补回缺失的材质细节。
- 正式游戏入口仍为 `TheophilusGameScene`。LR06 全图和本次效果对照场景没有进入正式地图。比较正式游戏和新 Blender 文件时，还包含地图版本差别。

源文件已重新输出建筑和走廊两个 8 采样参考图。Unity 使用相同位置、朝向、48 度垂直视角及 960×600 分辨率。图在忽略目录 `LocalData/BlenderLookStudy`。这个对照明确显示：稳定颗粒已能运行，但材质、暖光反射和间接光仍有明显差距。

## 稳定颗粒的范围

实现和开关见 [随机灯光实验](StochasticLighting.md)。它是可关闭的光照美术近似。没有实现 Cycles，也没有完成面积灯转换或全图光照烘焙。独立效果场景保留原模型和材质资产。

## 后续还原顺序

1. 先确认要接入的地图版本和同机位参考。
2. 按表面补齐颜色、粗糙度、金属度和法线。已有 UV 问题需单独修复，不能只调颜色。
3. 转换灯光，并为固定环境处理间接光和局部反射。可控灯仍需支持开关，动态角色也需受光。
4. 匹配曝光和显示变换，再微调颗粒。

不要用整体提亮、压黑或全屏噪点代替这些步骤。正式地图的 MC00 灯控会替换全局光照贴图和探针，接入新烘焙前须处理兼容性。
