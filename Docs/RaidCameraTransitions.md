# 部署与死亡镜头

`RaidHUD.Cinematics` 按本地 RaidClientState 和拥有者 Ghost 接入，不需要场景或 prefab 手动挂接，不改变服务端出生、死亡、物品掉落和结算规则。

## 部署

- 每次新 Raid 在本地玩家和相机就绪后播放一次，约 4.5 秒：地图俯瞰停留 0.65 秒，2.35 秒收近出生区域，1.5 秒落到实时更新的角色第一人称相机。
- 正式地图范围取当前场景 Terrain 和物资／撤离点；悬赏模式使用当前竞技场范围。
- 临时相机接管渲染，原相机继续计算最终位置；结束时恢复原相机，避免落点跳变。DollSinger 的临时相机复用第一人称身体裁切。
- 演出期间屏蔽玩法输入、地图和背包，隐藏游戏 HUD；没有额外客户端、录像缓存或双路场景渲染。

## 死亡

- 活着时缓存最后一帧相机姿态和角色脚下位置；确认死亡后，即使拥有者相机已销毁，也能继续呈现现场。
- 前 1.1 秒降低视角并向侧面倾倒；地面射线和小球检测限制落点，避免眼睛落入地板或墙体。第三人称死亡先回到身体附近。
- 到第 2 秒仍保留完整现场；随后 2.2 秒平滑淡黑，再保持全黑约 0.4 秒，约第 4.6 秒显示原有失败结算页。结算和仓库保存继续按原有服务端流程执行。
- 死亡后结果页保持黑色背景；新 Raid、退出地图、连接 World 失效或 HUD 禁用时释放临时相机和黑屏层。
- 悬赏模式只有 `ClashLife.Dead` 触发死亡演出；可救援的 `Downed`、成功撤离和超时不播放该死亡倒地镜头。
- 这是实时死亡镜头演出，不生成录像文件，也不是击杀者视角回放。

## 验证

2026-10-24：复用现有 Unity Editor，针对性 EditMode 检查确认地图概览高度、入眼位置／旋转连续、相机交还；死亡检查确认原相机销毁后仍可倒地、地面间距、先显示倒地再淡黑、全黑停留及状态释放。未进入 Play，未进行联机或主观视觉验收。

手动 Play 关注：首次进入和再次部署；室内／斜坡／第三人称死亡；地图或背包开启时死亡；黑屏后结算按钮；悬赏倒地后救援。最终节奏、穿模及画面效果仍以实际游戏体验为准。
