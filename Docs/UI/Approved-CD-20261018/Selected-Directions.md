## 第一批可编辑组件

- `Components/HomeCommandCard.uxml`：主界面三个主要入口共用内容层；父按钮保留原 ID 和回调，图像、标题、编号、箭头与焦点标记可分别编辑。
- `Components/ActionCard.uxml`：局内菜单复用三次；保留原来的继续、主菜单和退出回调。
- `Components/EquipmentSlot.uxml`：原有六个装备位共用；角色仍是原始独立渲染层。
- `Components/InventoryItem.uxml`：物品图标、名称、数量、焦点/选择边框分层；既有拖拽、旋转、快捷转移与事务不变。
- `Components/InventoryContainer.uxml`：容器标题、说明、区域组。
- `Components/MoonkovControls.uss`：颜色角色、边框与交互状态；`stateFx` 为可扩展、忽略拾取的独立反馈层，当前仅静态悬停/焦点/按下响应，没有新增循环或后处理。
- `InventoryTheme.uss`：仓库采用已选右版深色，局内背包/搜刮采用已选左版浅色，正交网格自适应容器宽度。

`TerminalMotion` 与现有换页 Wipe/Reveal/Fade 调用保持不变。其余已认可页面等待后续批次，本批未接入新玩法，也未移除旧模式和服务器数据字段。

本批仍是组件接入与第一轮美术修正。仓库图标和最新画面仍需视觉验收，不能把原生编译/布局检查等同于提案完成。
