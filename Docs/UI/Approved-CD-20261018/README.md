# Moonkov C/D 视觉选择册

打开本目录 `index.html`，逐项选择左、右、都可以或都不行，；选择“都不行”后，可选填反馈与指导（也可留空）。“都可以”表示两版均认可，不表示融合；左为 C，右为 D。再次点击已选项取消。选择保存在当前浏览器本地，点击“导出我的选择”得到 `Moonkov-UI-Choices.json`，将该文件交回即可继续。网页本身不联网、不提交意见。

这是一份图片提案选择册，不是所有界面均已在 Unity 实现的声明。00 为用户认可的原图，其他页面为基于现有 UXML/Presenter 的视觉提案。`catalogue.json` 记录页面入口和功能约束。非撤离模式的重生、战绩与调试面板单独列出，不添加到撤离玩法。

实际读取了 `.agents/skills/design-taste-frontend/SKILL.md` 及其 Unity 游戏界面参考，采用层级、字体、状态和实现检查，没有将网页框架搬入 Unity。

## 人物规则

- 不让图像模型重画项目角色。`Project-DollSinger.png` 来自 Unity 现有 `MenuCharacterView` 的透明 RenderTexture；模型、骨骼、动作与 prefab 未修改。
- 两张已认可的主菜单原图保持不变。仓库装备、局内装备、出击角色确认页使用独立原始角色层；UI 底图仅留空位。
- 设置、任务、商店、通讯、地点、简报、结算、HUD 和弹窗不加装饰人物。健康页的中性部位示意图属于操作信息。
- 仓库角色和格子是选择册中的分层展示；这些格子还不是已接入的可拖拽组件。

## 主菜单实际接入

原生 UI Toolkit，沿用 `StashScreen` / `MoonkovTerminal` / `MenuCharacterView` / 本地化与 UI 音频。

| 可编辑层 | 项目文件 | 作用 |
| --- | --- | --- |
| 布局与按钮 | `Assets/Resources/Moonkov/UI/Ship.uxml` | 出击主卡、两张中卡、五个服务入口；保留既有命名与回调 |
| 视觉样式 | `Assets/Resources/Moonkov/UI/ApprovedHome.uss` | 只作用于主菜单，C/D 主题、字号、间距、状态 |
| 图像资源 | `Assets/Resources/Moonkov/UI/ApprovedHome/` | 两张无人物背景、三张无文字卡片图 |
| 绑定 | `Assets/Scripts/UI/Game/MoonkovTerminal.cs` | 原功能入口；新增主题切换和原月球观察入口 |
| 原始角色 | 现有 `MenuCharacterView` | 独立实时 3D 层，没有烘进按钮或背景 |

关键参数：主菜单右侧宽 43%，常规最小宽 430px；卡片间距 12px；主行动字号 44px、常规行动 24px、服务入口 16px；小尺寸主行动 32px。品牌蓝紫 `#4430F0`，主背景白 `#F2F3F0`、黑 `#06070A`。边框 1px，焦点 2px；悬停与焦点用边框，按下用底色，禁用降低透明度。线条和交互状态脱离背景仍存在。

背景只用于主菜单，不传播成全游戏共用铺底图。图像中的颗粒为静态材质，无新增实时后处理；新增图像关闭 mipmap，使用 Clamp、双线性采样、压缩和不缩放非二次幂尺寸；未测显存/帧时。取消 USS 中相应 `background-image` 可移除装饰。未改变渲染管线、场景光照、质量或性能设置。

在 Unity 使用 `Tools > Moonkov > UI Preview` 查看主菜单。右上角 C / D 按钮切换主题；这里只是现有编辑器预览，使用示例物资，未连接账号。其他页面等待选择确认后再逐批拆分为 UXML、USS、图像层和状态组件。

## 自查与边界

- 继承月球尺度、黑白负空间、建筑切面与克制蓝紫；没有复制树木、伞状物、水印和播放器。菜单采用大小不等的指令卡，高密度页与 HUD 另行组织。
- 原生按钮文字、边框、选中与焦点独立于背景；其余生成图中的状态仅为视觉示意，不能认为交互已完成。
- 仓库保留正交功能网格；中文正文与数值应在组件实现时重新排版。生成文字、图标和示例数值均不能作为数据来源，未知经济数值用占位。
- 主菜单：编辑器 1600×900 布局和主题 NavigationSubmit 已检查；紧凑尺寸与导航的最终结果见 `Unity-validation.txt`。未验收实际 Play、账号联机、物理键鼠/手柄、超宽屏与性能。
- 离屏 UI 截图失败，未冒充运行图。选择册中的提案均不是 Unity 截图。没有真实性能数据。
- 完整悬停、键盘/手柄焦点、按下、选中、禁用、拖拽、错误和加载状态仍须按各页面现有输入系统逐批落地；本轮没有声称完成这些页面。

图像底图仍是位图；人物已独立，主菜单文字、按钮、卡片、资源绑定已独立。用户选中的其他提案之后才重建可编辑小组件，不能靠自动切一张整图宣称 Unity 完工。

已知提案偏差：31-D 生成图仍显示成功，失败标题与反馈状态需在选定方向后补齐；部分 C/D HUD 是不同明暗的室外示意，不能当作真实室内可读性测试。生成底图中的拼写与布局问题由选择页反馈决定是否保留重做。
