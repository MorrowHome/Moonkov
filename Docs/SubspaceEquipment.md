# 亚空间背包与可见护盾装备

分支 `feat/subspace-equipment` 基于项圈分支 `feat/nekomimi-life-support-collar` 的 `049426bc`。集成时需要此前项圈、护盾表现代码；未合入 develop。

## 穿戴辨识

- B-03 轻型：小尺寸单环亚空间锚，原有 3×4 格、0.45 kg。
- B-04 侦察：单环加成对稳定鳍，原有 4×4 格、0.7 kg。
- B-08 远征：双环亚空间锚，原有 5×6 格、1.3 kg。
- B-12 货运：大尺寸三环亚空间锚，原有 6×7 格、2.8 kg。
- S-100：腰侧独立护盾发生器，削角外壳、三片发射叶片、四段护盾量指示灯；能源耗尽时变为琥珀色，恢复时指示灯脉动。保留原有受击、破盾与恢复力场。

背部装置包含实体环框、匹配光环颜色的灯与动态空间口。环框在胸骨坐标内跟随躯干；护盾发生器在髋骨坐标内随身体移动。初始化时从身体和服装蒙皮顶点拟合间距，不新增碰撞体。极端动作下衣物与长发的动态交叠仍需实际对局观察。

## 接入

沿用 Backpack 和 Shield 槽、物品代码、容量、负重、掉落、存档及伤害规则。背包内容仍需转移至口袋或胸挂才能使用补给，不提供无限空间或零负重。

服务端从真实装备图生成 Ghost 字段 `SubspaceBackpack`：0 无、1 轻型、2 远征、3 货运、4 侦察。其他客户端据此显示装置。新增 Ghost 布局要求客户端与服务端使用同一版本。

仓库 `MenuCharacterView` 读取实际装备图，背包单独装备时也创建外观；本机第一人称通过现有逐相机隐藏与恢复流程隐藏装置，其他相机正常显示。所有四款背包均更新 UI Toolkit 原生矢量图标、中英文名称及描述。共享本地化表保留既有条目 ID。

网格由 `EnergyShieldGeometry` 引用计数共享，空间口沿用现有深度感知 RenderGraph Pass。没有增加相机、World、外部美术资源或永久全身护盾球。
