# 局内营养与负面状态

上一阶段的七部位健康、氧气和健康页继续使用。能量、饮水、胃容量由比赛服务器更新，同一份规则同时用于客户端移动预测和服务器移动、换弹及射击间隔。客户端使用操作只提交物品 ID、背包版本和请求序号；服务器验证所属连接、当前局、存活、携带范围及容量后，同时扣除一份物品并恢复资源。

## 资源与补给

| 资源 | 开局 | 静止时默认消耗 | 作用 |
| --- | --- | --- | --- |
| 能量 | 100 | 900 秒耗尽 | 低于等于 25 进入饥饿，0 进入饥饿耗尽 |
| 饮水 | 100 | 720 秒耗尽 | 低于等于 25 进入口渴，0 进入脱水 |
| 胃容量占用 | 25 | 600 秒消化 100 | 大于等于 85 为过饱，食物必须放得下完整一份 |

行走的能量和水消耗为静止的 1.1 倍；移动且冲刺时分别为 1.75、1.4 倍。腹部归零后再乘 2。胃容量不代表能量，空胃不会单独扣血；消化仅释放容量。脱水时即使满胃也允许饮水，胃占用封顶 100。

服务器用实际水平位移判断是否移动。顶墙按冲刺但没有前进时，能量和水按静止消耗；位置抖动、垂直位移和突然传送不算跑动。判定与耗氧使用同一份位移记录。

| 物品 | 占格 / 堆叠 | 一份效果 |
| --- | --- | --- |
| 远征口粮 `ration` | 1×1 / 3 | 能量 +45，饮水 -5，胃占用 +35 |
| 密封饮用水 `water` | 1×2 / 2 | 饮水 +50，胃占用 +10 |

供应商沿用当前免费采购规则，新增上述两种补给。偶数战利品箱产出口粮，奇数箱产出饮水。非持久化演示部署自动带各两份；持久化账号需要在仓库中准备并携带。已在地面箱子或仓库里的物品不能直接用于局内恢复，先转移到自己的携带容器。健康页可直接吃喝，也可在装备页右键使用。所有携带背包可用，医疗用品仍需口袋或胸挂。

进食需要 3 秒，饮水需要 2 秒。进度沿用局内动作光环，可按 X 取消。服务器在动作完成时再次验证物品与资源，再扣除一份并恢复资源。移动超过 0.75 米、受到攻击、开火、换弹、切换武器、库存变化、死亡或战局结束会中断；中断不消耗物品，也不产生补给效果。补给和其他手动操作互斥。资源全满、版本过期、背包不可达或胃容量不足也不会消耗物品。氧气罐和护盾充能保留原有使用方式。当前没有专门的吃喝手部动画。

玩家和普通局人形敌人开始吃喝时发出一次衣物声。8 米内的人形敌人和异形可调查，墙体缩短听距。客户端使用现有空间化衣物音效；本人的完成反馈保持原样。拒绝或重复的请求不会产生新声音。序号和隔离编译通过；实际听感、遮挡和服务端夹具尚未在编辑器验证。角色同步字段有变化，在线客户端和服务器需要匹配版本；本轮没有部署或联机验收。

带治疗效果的食物和持续再生只恢复仍有生命的部位。恢复量按角色当前的部位生命上限分配；上限降低时，不会把治疗量扣在已经达到上限的部位。若能量已满、所有存活部位都达到当前上限，且食物没有其他可生效的加成，就不能消耗该食物。

饥饿、脱水和缺氧的持续扣血不会反复打断吃喝或医疗。扣血在使用期间继续；如果生命耗尽，操作仍会失败。同一时刻受到实际攻击或护盾命中仍会打断，不能用持续扣血掩盖攻击。普通医疗仍会被燃烧、中毒或流血伤害打断；止血使用单独的自救规则。

## 实际效果

| 状态 | 默认效果 |
| --- | --- |
| 饥饿 | 步行 ×0.9，冲刺 ×0.8，跳跃高度 ×0.8 |
| 能量耗尽 | 步行 ×0.75，禁止冲刺，跳跃高度 ×0.8；缓冲后每秒损失 0.5 HP |
| 口渴 | 步行 ×0.9，冲刺 ×0.85，跳跃高度 ×0.8；换弹与射击间隔 ×1.1 |
| 脱水 | 步行 ×0.75，禁止冲刺，跳跃高度 ×0.8；换弹与射击间隔 ×1.25；缓冲后每秒损失 1 HP |
| 过饱 | 冲刺速度 ×0.85，直到胃占用低于 85 |
| 氧气 1～10 | 步行 ×0.85，冲刺 ×0.8，跳跃高度 ×0.7，操作间隔 ×1.1 |
| 缺氧 0 | 步行 ×0.65，禁止冲刺，跳跃高度 ×0.7；保留原氧气缓冲与胸部损伤 |
| 腿部归零 | 步行 ×0.65，禁止冲刺，跳跃高度 ×0.5 |
| 手臂归零 | 换弹与射击间隔 ×1.4 |
| 腹部归零 | 能量、水消耗 ×2 |

同时发生的乘数相乘；不是新建一个没有接入控制器的体力条。营养耗尽各有独立 10 秒缓冲，恢复对应资源即清除该项暴露计时并停止其伤害。伤害按剩余各部位组织比例分配，经原有死亡和结算流程处理；不存在饥饿瞬杀或单纯“胃空扣血”。健康页列出具体状态，局内 HUD 显示异常并对低储备播放间隔警报。

默认参数可在 `MoonRaidMap` 的 Survival 区域调整：两种储备耗尽时间、消化时间、营养缓冲和每秒伤害。处理仅针对正在局内的活玩家；死亡、撤离、超时后停止。下一局重新初始化储备，不在账号之间持久化伤病或饥渴。
