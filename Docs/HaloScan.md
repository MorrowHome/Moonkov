# 光环空间扫描

2026-11-06。扫描波显出周围空间，并穿透建筑探测敌人。基础能力不依赖地图剧情或研究解锁。

## 玩家规则

- 按 N 扫描。手柄为 RB 和右摇杆按下。按住不会重复触发。
- 每次消耗 25 点现有光环能量。冷却 8 秒。能量不足时不会启动。
- 光环在身边时从头顶发出。光环外放并到位后，从外放位置发出。派出和归位过程中不能扫描。
- 扫描半径 24 米。波以每秒 18 米向外推进。建筑不会阻止敌人探测。
- 地面、墙面、建筑转角、台阶和物体表面随波亮起。显示轮廓、网格、扫描点和高度线，然后淡去。表面效果依据实际画面深度，不修改原材质。
- 波扫到敌人当时的位置后，显示橙色标记和短时穿墙轮廓。标记保留发现位置；有可用模型时，轮廓显示模型的短时姿态。3 秒后消失。
- 扫描不显示容器内容，也不自动完成调查或任务。友军不标成敌人。已死亡、已消失和超出范围的目标不返回。
- 扫描与手持射击共用能量。外放后的自身攻击限制仍然有效。区域护盾和自动射击继续互斥。

## 权威与预算

- 服务端验证角色、战局连接、冷却、光环状态和能量。客户端只发扫描意图。
- 触发时查询范围内目标，最多保留最近 24 个。按波抵达的时间向扫描者连接发送结果，不广播给其他玩家。
- Ghost ID 和生成 tick 同时参与身份判断。序列号拒绝重复和过期消息。死亡、离线和换角色时清理结果。
- 地形效果使用一个临时 URP Render Graph Pass，仅作用于拥有者的实际游戏相机。不改渲染管线资源，不增加相机、灯光或环境网格。
- 扫描期间复用数组、材质和属性块。轮廓最多提交 96 个模型绘制。只在收到合法目标时缓存其模型，不逐帧搜索场景。
- 没有扫描波或有效目标时，不提交额外绘制。相机失效或状态停止发布时释放效果。

## 验证入口

- `HaloScanChecks.Run()` 检查实际服务端扫描、穿墙探测、敌我、范围数量上限、耗能、冷却、消息归属、生命周期与生成的命令序列化。
- `HaloAbilitiesReview.Capture()` 以实际 URP 相机渲染地面、墙、台阶、柱子和遮挡后的目标，保存扫描前后对照。同时检查 13 种正式光环的定点外观与防御图案。
- 本地证据在忽略目录 `LocalData/HaloAbilities`。预览使用隔离场景和样例状态，不是正式战局录像。
- 单 Editor 验证不替代联机验收、完整战局手感和目标设备性能测试。
- 新能力改变 Ghost 和 RPC 协议。客户端和服务器须使用同版；旧发布包不会自动更新。
