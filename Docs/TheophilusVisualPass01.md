资源位于 `Assets/MoonEnvironment/Variants/TheophilusBase/VisualPass01`。重新应用入口为 `Tools → Moon Environment → Theophilus → Apply visual pass 01`；已有正式资源直接复用，不改写共享研究场景配置。

## 第二轮：柔光与油润高光

第二轮最初使用 Dual Bloom（强度 3、阈值 0.55、散射 0.92），导致室外白色建筑和角色被大范围泛光冲淡。这组参数已撤换，当前参数见下方修正。曝光不继续提高；对比度改为 4、饱和度恢复至 0，强化冷阴影与暖高光。

东侧 EVA 门楣和 G03 两盏顶灯使用正式地图专属 HDR 发光材质，暖白发光为 `(18,13,8)`。只替换三处灯罩及原 `LightCircuitControls` 中对应的 onMaterial，原 offMaterial、光照强度、照明与网络权威不变。重新应用工具会重绑原回路适配器，更新缓存的材质槽，避免编辑器内旧缓存影响关灯表现。

灰漆、陶瓷漆和深色合金增加强度 0.3、光滑度 0.82 的清漆反射；积尘遮罩会削弱清漆。铝和不锈钢的基础光滑度改为 0.62。没有新增透明雾层、运行时更新脚本、实时灯或阴影捕获。

最终 Unity 编译及 Shader 检查通过，三处发光绑定关灯/开灯回归通过。使用原生 URP StandardRequest 进行同机位对比；临时红色调色探针确认后处理通路工作，探针已恢复。初期关于“未执行 URP 后处理”的判断没有得到证实，以最终检查为准。Console 仍有原有 Package Manager/SubScene 问题，临时诊断脚本的错误不属于交付代码。

RTX 4070 SUPER、1440×900、每机位预热 4 次、采样 12 次：参数/清漆对照中，入口提交与等待耗时中位数 13.90 → 11.34 ms，G03 为 5.62 → 4.87 ms。两阶段共用最终灯罩发光和静态反射；编辑器波动较大，不能称 FPS 改善或给出性能保证。没有运行 Play、Host/Client 或目标显卡整图验收。最终截图、原始数据和关灯回归位于 `Library/BuildValidation/TheophilusAtmosphere`。

本轮场景仅改三个灯罩材质引用和一个回路绑定组件；用户原先九个场景修改记录继续排除。重新应用入口为 `Tools → Moon Environment → Theophilus → Apply soft light atmosphere`，灯罩绑定入口为同目录 `Apply atmosphere lamp emission`。

本次仅修改 Profile、重新应用工具和本记录，不修改场景、材质、实时灯或运行脚本。检查后关闭临时加载的正式地图，恢复 MainMenu、原渲染管线和抗锯齿设置；未进入或退出 Play。

## 2026-10-24：中央建筑蓝色反射

单变量对照确认，正式地图在黑色太空背景下仍以强度 1 使用 `Default-Skybox-Cubemap` 默认天空反射。将 `RenderSettings.reflectionIntensity` 临时设为 0 后，中央金属建筑的明显蓝色反射消失；太阳与补光均为白色，材质的轻微冷灰底色不是主要原因。

正式场景的 `m_ReflectionIntensity` 与 `MoonSceneLighting.environmentReflectionIntensity` 同时设为 0，覆盖编辑器与运行时的默认环境反射。房间 ReflectionProbe 的贴图、强度与供电回路不改。没有用全局去饱和压掉角色、警示色或灯光颜色，也没有禁用材质的局部探针采样。

固定机位与上一节一致，单变量对照位于 `Library/BuildValidation/LunarCast/baseline.png` 和 `no-environment-reflection.png`；预热两帧、线性 HDR 转 sRGB 输出。正式场景仅精确修改这两个标量，未通过 Editor 重存；已有场景差异保留并排除于提交。未进入 Play 或联机验收。

## 2026-10-24：月面材质与近景碎石（当前候选）

上一轮反射强度 1.5、底色 0.85 的白化试调已替换。当前保持全局曝光 +1.30 EV，正式月壤反射强度降到 1.10，中性底色 0.78（按用户最新的过白反馈，相对中间候选约降 0.45 EV），岩相底色 0.8；地质遮罩强度从 0.9 降到 0.4，新鲜喷出物亮度从 0.35 降到 0.06，减弱小坑的规则亮色圆环。粉尘底色保持中性。没有进一步提高建筑、角色或室内的全局曝光。这是摄影观感的艺术标定，不是实测反照率拟合。

`TheophilusSky.mat` 的日照星光可见度从 0.5 调到 0，夜间原有星光强度不改。正式月壤通过 `_PhotographicSurface=0.85` 启用带屏幕足迹过滤的四级粉尘微法线；在远处逐渐退出，避免亚像素颗粒闪烁。没有新增全局后处理、渲染功能或 Shader 变体。根据岩石与地表割裂的反馈，正式地图加载时，岩石运行时材质副本的主体与积尘共同读取月面的颗粒贴图、颜色、反射标定和地质变化参数。`_SurfaceMatch=1` 时，将扫描贴图的局部明暗与少量色相变化重新锚定到当地月壤反射，避免扫描底图再叠加旧深色底色而过度变黑。主体漫反射输入限定在当地月壤约 0.72–1.13 倍范围；几何法线、投影和受光方向仍决定实际画面明暗，背光面不会变成自发光。纹理法线与光滑度适度收敛。共享源岩石材质不改；未启用匹配的材质保留原数学路径。原材质控制为 0 时，其他地图沿用原逻辑。

`MoonRegolithDebris` 为关闭了原运行时地形雕刻的正式地图补充纯显示碎石。覆盖真实地形并跳过地形孔洞，直径 2.5–30 cm，部分埋入地面。每帧至多生成两块 20m 分块，最多保留 25 块，每块最多 64 件；上限为 230400 顶点 / 76800 三角形，26–36m 淡出，淡出终点在至少 40m 的覆盖边界以内。没有新增碰撞体、TerrainData 写入、导航或网络状态。无图形设备的服务器不创建这层显示。
