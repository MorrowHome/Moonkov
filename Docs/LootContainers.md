# 场景搜刮箱

月球正式联机地图已有物资点现在显示为测试搜刮箱。每位玩家每战局首次搜索同一容器需服务端计时2秒，关闭/X可取消，完成前不能取物；异形解剖仍为6秒。Ctrl快捷转移仅寻找口袋和已装备胸挂/背包的直接格位，不自动套入嵌套包，显式手动放入仍支持。随身物品支持右键丢弃到可重新拾取的地面容器，详见[局内丢弃与耗时操作](RaidTimedActionsAndDrop.md)。靠近按 E（手柄 X）打开，左侧是共享箱内物品，右侧是口袋、胸挂和背包。支持现有拖动、旋转、拆分、合并、整包移动及 Ctrl 点击快速转移。Tab/关闭/ESC 退出；等待物品确认时暂不关闭，避免关闭请求抢在转移请求之前处理。角色装备视图仍通过普通 Tab 打开。

饥饿、脱水和缺氧的持续扣血不会反复打断搜索，玩家仍可冒险找补给。搜索期间伤害继续；死亡会终止搜索。新的身体伤害或护盾命中仍会打断，包括与生理扣血发生在同一服务器时刻的命中。

每个服务器 World 按当前地图为物资点初始化独立容器树，箱内物品具有唯一 ID。补给、医疗、工业和装备四类箱子采用保底物资与加权随机池，包含食物、水、氧气、电池、医疗、材料、模块及少量装备。箱子搜空仍可打开，也允许存入随身物品；关闭 UI、玩家重连或重新出战不会重置共享箱子。

建筑抽屉按房间用途使用小型物资池，每个抽屉最多有两种物品，也可能为空。生活抽屉增加补水和氧气；医疗抽屉有少量生命针、解毒针和氧气；工业抽屉有少量供能模块、氦-3 样本和量子核心。高价值物品仍比常见材料稀有。敌人和玩家争夺同一份抽屉内容，不额外生成奖励。

四类抽屉共 4000 次固定种子抽样和真实库存转移检查通过。工业抽屉的 1000 次样本中有 9 个量子核心、22 个氦-3 样本和 53 个数据盘；这只是规则抽样，实际 30 个抽屉的收益仍需结合地图和敌人密度试玩。后端箱子与丢弃检查通过；游戏与编辑器程序集隔离编译通过，尚未实测正式战局。

正式 Theophilus 地图的空箱冷却为 300 秒，每箱最多补货 2 次。有在局存活玩家，且箱子 18 m 内无人、无人查看时才补货；任何剩余物品或玩家存入的背包及其内容都会阻止重置。新物品使用新 ID，箱子版本递增，旧版本转移继续被拒绝。尸体容器不补货。更换地图时重建共享箱子并关闭旧箱子访问；完整配置与位置编辑见 [战局刷新说明](RaidSpawning.md)。

```mermaid
flowchart LR
    E[靠近按 E] --> O[服务端验证战局/存活/距离/视线]
    O --> U[箱子与随身容器的合并显示快照]
    U --> C[拖动意图 + 两份版本号]
    C --> V[服务端原子验证与转移]
    V --> P[玩家独立物品树]
    V --> L[共享箱子独立物品树]
    L --> W[刷新所有正在查看该箱子的玩家]
    P --> S[撤离只结算实际携带物品]
```

## 权威与一致性

- `RaidLootOpenRpc` 只请求开箱/关闭，服务器保存当前可访问的箱子；`RaidLootMoveRpc` 同时携带玩家版本、箱子版本及对应箱子编号。
- 开箱和转移都验证当前战局、角色存活、已打开的箱子、取物距离和 Default/Ground 遮挡。服务器周期复核，走远、失去视线、死亡或结算后关闭访问。
- `LootInventoryExchange` 在副本上执行现有容器规则；成功后一次替换双方物品树。失败不改任一方的版本或物品，保留 ID、数量、拾取标记和嵌套内容。两人用同一箱子旧版本拿同一件物品，只有先到的操作成功；后到的收到 Stale 和新快照。
- 联机 UI 的合并显示图带有 `loot` 根容器，玩家真实战局图不含该根。向账户持久化和撤离结算接口传入箱子图会被拒绝，避免误把整箱物品存入仓库。
- 快照复用 400 字符分片 RPC，额外封装箱子编号和版本；已有分片组件的内存布局未变。客户端与服务器须更新到同一版代码。旧即时拾取 RPC 不再生成物品。

## 检查与验收

`Tools > Moonkov > Check Loot Containers` 在 Edit 模式检查 24 个箱子初始图、双人同物品竞争、存入/拆分/合并、跨容器装备替换与嵌套内容、超重失败的原子回滚、箱子与结算隔离、分片元数据、实际生成的转移 RPC 以及 UI 双栏/快速转移请求。

后端 `ContainerChecks` 增加账户和结算拒绝 `loot` 根的检查，共 72 项通过；全部使用临时数据库，不修改正式资产。Unity 搜刮箱检查通过，后端编译通过并已重新启动。没有自动 Play、截图或自动 commit。

手动验收：

1. 进月球地图，靠近一个搜刮箱按 E；左右两侧均有标题、网格和物品。
2. 拖出一件物品并 Ctrl 点击存回；关闭再开箱，内容保持一致。Tab 查看随身背包。
3. 两个客户端打开同一个箱子，同时拿同一件物品；一个成功，另一个刷新，其他查看者同步看见变化。
4. 走远/被遮挡后确认界面关闭且不能继续取物；死亡和撤离同样结束访问。
5. 撤离后确认仓库只增加实际携带的物品；箱内剩余物品不进入结算。

上面的检查记录属于原搜刮箱交互版本；本轮增加随机掉落与有限补货，未扩展为完整联机验收。美术开盖动画仍未实现。
