# 敌人流体容器造成的滤镜方框

左侧为修复前，右侧为修复后；同一相机、正式地图的 MC00BakedPipeline、既有 Volume 与银盐参数。

![流体容器遮罩修复前后](01-fluid-proxy-before-after.png)

这是受控的原生 Shader 复现：使用实际 `Umbra08FluidSurface`、立方体容器和球形测试密度，绿色为角色表面，橙色背景正常应被处理成钴蓝。修复前把容器整个网格当作角色遮罩，保留了一整块橙色背景；修复后只保留真正命中的流体。此图不是战斗中的敌人截图。

遮罩重用流体射线步进、真实深度、丝线/黏液顶点变形和透明特效的 alpha 覆盖；普通不透明角色遮罩也改为与已写入的深度重合。原生覆盖通过 RendererList 绘制，保留 SpriteRenderer 数据。

必要检查记录见 [metrics.txt](metrics.txt)：比较同机位的像素最大通道差值（8 位输出），分别检查容器空白区、普通角色、流体表面、墙后遮挡和透明 Sprite 的空白/可见区域。另编译当前平台的八个相关遮罩 Pass。临时对象、加载场景、相机纹理、效果强度和管线设置在检查结束后恢复；未保存场景修改。

这些结果覆盖编辑器原生渲染复现；未进行 Play 战斗、Host/Client、构建或 GPU 性能验收。验证期间全工程重编译另有 `RaidMissionSite.cs` 的 CS0266（`ISoundSystem` 赋给 `SoundSystem`）；本次未修改并行任务的代码，遮罩运行时与上述 Shader 渲染通过不代表全工程编译通过。
