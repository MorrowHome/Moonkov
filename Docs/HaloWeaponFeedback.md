# 光环武器声音与命中反馈

四种武器共享现有池化音频和落点粒子机制，通过 `Assets/Resources/Moonkov/RifleFeedback.asset` 的 Rifle / Revolver / Shotgun / Sniper 配置区分。当前声音与视觉以文末 2026-10-16 版本为准；以下保留早期版本的背景与验证记录。

| 武器 | 发射声音 | 落点与命中确认 |
| --- | --- | --- |
| 左轮 | 干脆的 .445 发射主体，较高的短能量起音 | 轻快碎屑，暖白、短促命中标记 |
| 霰弹 | 更低的散弹主体，短促能量尾声 | 每枚弹丸保留落点，较小碎屑；提示音按一次发射合并 |
| 狙击 | 最强的低沉主体、明亮起音、延后的低音金属尾响 | 更大、更快的碎屑，非身体表面的短蓝白闪光；更粗、更久的冰蓝命中标记 |

狙击的手腕释放从 14 mm / 3° 增至 24 mm / 5°，外围光环扩大并短暂增粗。中心光点、相机、射线与伤害参数不随反馈移动。命中击杀保持金色。

## 音频来源与调节

复用已入库的 Sonniss GDC 2024 发射、金属、能量素材，以及项目原有 FPSSample 散弹素材。未生成、下载或重新分发额外音频。源素材与许可继续见 `Assets/Audio/Moonkov/Sources.json`、`Edits.json`、`Licenses/` 和项目原有许可证。

`Tools > Moonkov > Weapons > Create Missing Weapon Feedback` 只创建缺失 SoundDef、补充缺失引用，保留已有混音和表现参数。新 SoundDef 以导入 PCM 峰值校准，使用较窄的音高随机范围。狙击三层目标峰值分别为 -5.5 / -19 / -23 dB，线性和小于 0.72，为混音留出余量。远处声音使用现有 3D 衰减；命中确认只由射手以 2D 播放。

可在各 SoundDef 调音量、音高、空间衰减和尾音；在反馈库调碎屑比例/速度/数量、命中颜色/时长/线宽、落点声音间隔。

## 表面精修

岩面落点使用有切角和明暗分面的灰色岩屑，并带最多 3 粒短时、低重力抛射的月尘；没有持续烟雾或湍流。金属火花有窄亮芯，从暖白降温到橙色余烬后消失；MC00 的 `Brushed_Aluminium` 同样识别为金属。狙击继续保留极短的蓝白接触闪光，身体命中保持独立色彩。

固定复用 16 个落点槽，每槽两层：最多 12 粒碎屑、4 粒月尘/闪光，总粒子预算仍为 256。所有材质共用原 `RifleImpact.mat`，以缓存的 MaterialPropertyBlock 选择 shader 外形；射击时不新建材质、对象或贴图。槽位重用先清空两层，防止前一次岩面月尘残留到金属/身体命中。两个渲染层可能增加同时活动的透明绘制次数，尚未做性能实测。

## 联机职责

客户端仅预测落点，伤害和击杀确认来自服务端。落点 RPC 携带武器和弹丸编号；预测与确认按射手、发射 tick、武器、弹丸去重。命中提示按射手、发射 tick、武器合并，一次发射最多一次普通命中提示，之后若有致命弹丸可升级一次击杀提示。无有效伤害和旁观者不会得到命中确认。霰弹落点声音共享 75 ms 间隔，避免八枚弹丸堆叠八声提示。

RPC 结构变化后，服务端和客户端需要一起重新编译/打包。缓存固定容量、保留 6 秒，不作为伤害判定依据。

## 验证边界

此前声音与命中确认版本的 Unity 编译通过。临时单机战局中三种武器均完成服务端弹丸伤害、落点 RPC、普通/致命命中确认；霰弹八枚弹丸保留独立落点并合并提示，重复 RPC 不重启反馈，无伤害与旁观者不获得命中标记。三种发射音均通过现有池化 AudioSource 播放且采得非零输出。狙击实际手腕位移约 20.9 mm，光环中心与相机稳定，大拇指未遮挡准心。临时存档隔离，结束后已返回菜单并退出 Play Mode；未生成额外截图。

2026-10-13 表面精修保留原伤害、RPC、预测去重与音频逻辑。脚本及 shader 导入编译通过，正式离线场景中直接调用 `Present` 检查了岩屑、月尘、火花的运行画面，未把它当作本轮实弹或多人验证。截图在 `Library/BuildValidation/visual-impact-probe.png`。最终主观音量与力量感仍需要实际游玩判断；未进行完整多人对战或全量构建验收。


## 2026-10-16：视听打磨（mac/shooting）

本轮针对画面和声音。伤害、射速、散射、弹速、能量规则与相机朝向不变。

### 发射声替换

按用户反馈保留霰弹枪的三层素材、原音量和原播放/淡出方式。步枪、左轮、狙击改用免费实录素材：

| 武器 | 新主体 | 声音处理 |
| --- | --- | --- |
| 步枪 | AR-15，三段实录 | 240 ms 紧凑发射声，增强主体，轻微起音层；连射保留每发冲击，逐步交叉淡出前一发 |
| 左轮 | Smith & Wesson 642，三段实录 | 480 ms 发射声，保留短促枪口冲击和低频主体，移除原高亮能量主起音 |
| 狙击 | Mosin Nagant，三段实录 | 720 ms 主体，轻起音与延后 18 ms 的低频尾响，移除原金属敲击尾音 |
| 霰弹 | 原有 FPSSample 主体与两层既有素材 | 本轮保留 |

来源为 [The Free Firearm Sound Library](https://opengameart.org/content/the-free-firearm-sound-library)，CC0 1.0。作者、下载地址、截取位置、来源与成品 SHA-256、PCM 指标均记录在 `Assets/Audio/Moonkov/ShootingSources.json`，许可说明见同目录 `Licenses/FreeFirearmSoundLibrary.md`。源包保留在忽略的 LocalData；正式项目只增加 11 个短音频，不包含整个素材库。`Tools/Audio/build_shooting_audio.py` 可重建这些剪辑与独立试听。

新音频统一为 48 kHz 单声道 PCM，起音对齐，35 Hz 以下抑制，按角色调整低频、做并行软饱和与淡出，成品峰值 -1 dBFS。起音层是实录的高频部分，不再叠加铃声。步枪/左轮/狙击主体最大增益分别为 -6 / -5 / -4 dB，单次三层的保守线性峰值和小于 0.8；试听干混峰值约 0.563。音量仍经过原 SFX 总线和用户设置。

本人主体/起音/尾响空间混合分别为 0.08 / 0 / 0.2；其他玩家与敌人的对应枪声保持 1.0 的世界定位与距离衰减，并随距离滤去高频。使用原池化 SoundSystem；每次播放的覆盖值不会修改共享 SoundDef，也不会遗留到复用的下一声。发射事件继续按 tick 去重。

`Tools > Moonkov > Weapons > Install Shooting Audiovisual Revision` 可重新应用本轮声音配置；这是显式安装操作，会更新步枪、左轮、狙击的发射定义与声音引用，不修改霰弹声音。

### 画面层次

- 四种武器增加 75–120 ms 平面释放光：分段弧线与短射线从外围散开后消失，中心瞄准区留空。每名角色复用一个 144 顶点网格和既有材质；同 tick 的预测/同步事件不会重启。开火对已有光环点光及背面手部灯增加短脉冲，不增加灯光对象。
- 第一人称普通光环根据实际眼睛到光环的距离和当前 FOV 限制尺寸，默认外缘包络不超过画面高度的 54%；解决手臂可达距离缩短时图形被放大、切出屏幕的问题。狙击沿用其 80% 光学窗口配置，并改用真实距离计算；第三人称保持原大小。
- 弹道改为细尾、亮头的渐变。步枪/左轮/霰弹/狙击的最长拖尾分别为 2.6 / 1.8 / 1.3 / 6.5 m，眼前 0.55 m 内不显示拖尾。两个端点使用同一弹道年龄，另有长度上限，避免网络弹体刚加载时从原点拉出整条快照距离。碰撞仍从原始发射位置开始。
- 飞行灯范围上限 3.2 m；霰弹只让第 0 枚弹丸照明，八条弹道仍各自显示。减少大面积染色，保留发射方向和飞行头部的辨识。
- 岩面与金属增加短时表面接触痕：先有极短的亮边，随后留下灰暗接触点并在 0.85–1.1 s 内淡出。人物表面不贴此痕。与现有碎屑、月尘和火花复用固定 16 个落点槽，额外最多 16 个小四边形，粒子预算仍为 256；槽位复用与禁用会清理旧痕。

### 验证与边界

`MoonkovShootingAudiovisualChecks` 检查三种新主体各三段、PCM 参数与峰值、分层余量、霰弹引用、池化空间参数复位、释放去重/过期/准心留白、100 m 快照距离输入下的拖尾限额、非主霰弹飞行灯、落点和接触痕容量及复用。原射击、脉冲、头部遮挡与弹道检查一起通过。URP 落点 shader 无编译诊断；已生成并查看四种光环的静止/15/60/160 ms 对比图。

正式地图以独立临时单机档案运行真实 ClientWorld/ServerWorld，步枪发射 13 发，狙击/左轮各 2 发；最终两端均为左轮、4 发余弹、射击 tick 1561。新发射声经现有池播放，采得本人主体 0.08、起音 0、尾响 0.2，以及远端主体/起音 1.0 的空间参数；本轮采样的实际混音峰值约 0.268。近靶检查中记录到的最长可见拖尾约 2.6001 m（含远场坐标浮点误差）。用临时金属靶检查近距离画面与落点；这些靶、图片、探针和临时档案均不写入正式场景或玩家存档。

已返回菜单、释放临时档案、恢复玩家名称并退出 Play；Console 当前错误数为 0。

本轮未做独立远端双客户端、平台构建或 GPU 帧时测量；声音主观质量仍以实际试听反馈为准。调音入口为 `RifleFeedback.asset`、各 ShotBody/ShotSnap/ShotTail SoundDef，普通光环占屏比例位于 DollSingerHaloAim。

## 2026-10-23：可控后坐与连续反馈

本轮增加实际瞄准后坐：本人有效开火事件通过现有 tick 去重后，在下一次输入采样向上推动视角；后续发射沿同一瞄准方向计算。第一、第三人称共用这条输入路径。单发角度按武器区分，普通步枪为 0.34°、左轮 0.72°、霰弹 1.05°、狙击 1.2°，完整参数在 `HaloRecoilResponse.KickDegrees`。角度除以当前实际瞄准倍率，累计未回收后坐上限为 3° / 倍率。

每发之后等待射击间隔的 35%（最长 120 ms）开始指数回稳；间隔读取武器的普通射击或点射组内间隔，并应用既有操控状态倍率。快速连射能在两发之间回稳，慢速重武器保留较长冲击。玩家向下压枪会扣除对应回稳量，避免自动回稳把已经压好的准心继续往下拖。俯仰上限不产生虚假的回稳量；换枪、死亡、倒地、取消瞄准、自由观察、输入阻塞和角色生命周期清理待处理后坐。接入正式角色表现与输入路径，独立光环展示场不用于验证实际后坐。

手部释放响应改为有限的连续冲量叠加，修复下一发把尚未结束的回弹突然重置到零的问题。普通命中提示每次重新脉冲，击杀使用金色和分叉端点；普通命中不会盖掉仍显示的击杀，也不会无限延长它。命中确认仍来自服务端，伤害、射速、散射和音频素材保持既有配置。

验证：Unity 编译通过；`MoonkovShootingFeelChecks.Run`、`MoonkovShootingAudiovisualChecks.Run`、`MoonkovShotChecks.Run`、`MoonkovViewInteractionChecks.CheckCamera` 全部通过。覆盖压枪回稳、30/60/144 Hz、连续射击限幅、高倍率、第一/第三人称镜头与射线一致、连续回弹与事件去重、命中/击杀时序，以及既有输入缓冲、射击节奏、头部命中和遮挡检查。编辑器保持 MainMenu、非 Play、场景无未保存改动。本轮没有实战试玩、多人验收、平台构建或性能实测；这些检查不替代最终主观手感验收。

同日追加长连射检查：原固定 120 ms 等待在每秒 10 发连续 40 发后达到 3° 上限，最后一发实际冲击为 0；调整后同一响应探针最后一发为约 0.34°，该发间隔结束后的剩余上抬约 0.288°。新增检查覆盖 50/75/100/160 ms 发射间隔、30/60/144 Hz 积分步长和 1/6 倍瞄准，共 24 种组合，每种连续 40 发，确认后段每发仍有冲击、累计上抬受限、松开后回稳。射击手感、音画反馈、视角与瞄准检查再次通过。此处数值来自响应与输入检查，不是实战采样。
