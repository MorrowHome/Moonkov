# 商店与应急补给

登录账号后，从 **SUPPLIERS → VIEW SUPPLIER** 打开商店。购买使用月尘，物品进入个人仓库；出售需要先将物品收回仓库。所有供应商暂时使用同一份基础货单。

## 购买界面

购买页使用商品网格。每格显示图片、名称和单价。可以按中英文名称搜索，也可以按武器、装备、物资或模块分类。

鼠标悬浮时显示用途和关键数值。点击商品后，右侧显示大图和完整信息。数量和购买按钮固定在右侧底部。选择商品、搜索或查看信息不会下单。免费商品会说明不能出售。

购买、出售和仓库整理先在本地显示结果。余额和空间同时预留，可以继续操作，不必等上一份回包。后台按顺序提交。购买或拆分的新物品也可以立即移动；确认后会对应到服务器生成的真实物品 ID。

仓库、商店和改装台共用一个队列。关闭窗口或切页不会取消已提交的操作。回包到达后保留后续未确认操作、选择和数量。服务器明确拒绝时，回退失败操作及无法继续的关联操作，保留已确认结果和仍有效的其他操作。

价格和免费补给限制仍使用服务端货单。正式库存和保存仍由服务器决定。本地预演只用于菜单显示。准备、出战、退出账号、切换档案或使用游戏内退出按钮前，会先等待队列确认。普通浏览和连续整理不会因此锁住整个界面。

超时不代表交易失败。后台会有限重试同一份请求，不换订单 ID。仍无法确认时保留待确认结果，显示“重试同步”。此时暂停新增操作，避免继续叠加不确定结果。队列最多保留 64 项，正在同步时使用原状态位置提示。队列保存在内存中，强制结束进程不会保存尚未发出的操作；重开后以正式库存为准。

界面入口为 `MoonkovShopView` 和 `MoonkovShopPurchaseView`。信息内容与仓库共用 `MoonkovItemInformation`。2026-11-06 单 Editor 编译和 33 项原生检查通过，使用隔离库存验证真实购买规则。已查看原生网格与详情。没有进行真实账号购买、联机或 Player 构建验收。

## 商品与交易规则

| 物品 | 买入月尘 | 卖出月尘 | 占格 |
|---|---:|---:|---|
| 步枪光环 | 0 | 20 | 2×2 |
| 六发左轮光环 | 0 | 7 | 1×1 |
| 霰弹枪光环 | 0 | 25 | 2×2 |
| 狙击光环 | 0 | 45 | 2×2 |
| 能源电池（满电每个） | 0 | 2 | 1×1，最多叠 12 个 |
| 医疗注射器 | 0 | 3 | 1×1 |
| 食物 | 0 | 2 | 1×1 |
| 饮水 | 0 | 2 | 1×2 |
| 氧气罐 | 0 | 3 | 1×1 |

当前基础枪械、电池、医疗、食物、饮水、氧气罐和两款生命维持项圈可免费领取。新领取的免费商品带应急补给标记，不能出售，也不能与普通物资合并。购买前会显示这个限制。同类战利品和付费商品仍可出售。旧存档中已经领取、没有应急标记的物品保留原状，仍可出售，不会追溯修改。

在线商店以服务器返回的货单为准。旧服务器未更新时仍沿用旧交易规则，新客户端不会提前显示新的出售限制。服务器更新后，新货单才会显示限制。本轮没有部署服务。

这是测试阶段的防刷钱措施。免费武器和补给仍可反复领取，正式经济尚未平衡。定价需要结合地图路线、死亡损失和连续失败后的恢复能力试玩。

每节满电电池有 100 能量，买入为满电，卖出按实际卖出电量折算月尘、向下取整。拆卖部分堆叠优先卖满电电池，保留未满电池及其余量。具体充能规则见 `BatteryEnergy.md`。

输掉全部光环时，进入 **SUPPLIERS → EMERGENCY SUPPLY → CLAIM FREE KIT**，免费领取一把六发左轮和 3 个能源电池。左轮自动装备在手枪槽，电池优先放入可携带空间；空间不足时尝试放进仓库。若整包无法安置，领取失败且库存不变。

领取条件检查整个物品树，包括容器内的光环；已有任何光环时不能领取。应急物品不能出售，不能与普通电池合并；移动、部署、死亡掉落和撤离都保留应急标记。之后再次失去全部光环，可以再次领取，不设置每日等待。

交易期间不能处于未结束战局。价格由服务端提供，交易在后端持有玩家行锁的数据库事务中完成，同时检查库存版本。每份订单使用唯一请求 ID 和内容指纹；网络中断后仍重试原订单，重复请求不再次扣款或发货。资金不足、仓库满、过期库存或不允许出售等失败均不改动正式库存。`inventory_trades` 为增量数据库迁移，不重建旧存档。
