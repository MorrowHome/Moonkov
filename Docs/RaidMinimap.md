# 游戏内实时小地图

小地图由现有 `MoonRaidMap → RaidHUD` 入口自动创建，正式 Theophilus 地图无需手动挂组件。继续使用 UI Toolkit 和本地客户端的 `GhostOwnerIsLocal` 查询，不新增网络消息或修改服务器判定。

- 右上角显示北向固定、随自身位置移动的 240 × 240 米地表俯视图。白色箭头指向本地视角的水平方向，俯仰到垂直方向时保留最后一个有效朝向。
- 金色方框显示地图已有的物资点；服务器 `TakenMask` 标记空箱时变灰并划线，补货后随快照恢复。
- 绿色菱形及圆圈表示撤离信标与范围；信标超出地图时显示边缘方向箭头。底部显示水平距离，不代表可行走路线。
- 地形与建筑使用真实场景渲染，256 × 256 RenderTexture，每 0.2 秒刷新；位置和方向逐帧更新。投影使用最近一次底图的中心，避免两次采样之间标记与底图错位。
- 关闭额外相机的阴影、后处理、HDR、MSAA、颜色及深度复制；排除 UI、第一人称覆盖层与玩家层。不提供敌人雷达。
- 打开背包、暂停、死亡、结算、离开对局或等待本地状态时隐藏并停止底图采样。HUD 禁用时释放相机、纹理和绘制回调。无图形设备或不支持渲染请求时保留导航标记并提示无影像。

这是地表概览；室内屋顶、上下层和深井不转换成楼层导航。

## 编辑入口

- `Assets/Resources/Moonkov/RaidUI.uxml`：固定结构，可用 UI Builder 编辑。
- `Assets/Resources/Moonkov/UI/RaidMinimap.uss`：地图尺寸、位置、配色及周边仪表避让；氧气仪表位于左侧网络状态下方，撤离提示位于小地图下方。
- `Assets/Scripts/Gameplay/UI/RaidMinimapView.cs`：覆盖范围 `HalfRange`、采样间隔 `CaptureInterval`、投影与标记。修改显示边长时同步 UXML 的覆盖范围文字和 USS 比例尺宽度。
- 中文沿用 `MoonkovUI` 字符串表与现有字体，没有重建字体资产。

## 本次验证（2026-10-19）

Unity 6000.5.10f1 编译通过，`scriptCompilationFailed=false`。通过现有单人入口进入正式 `TheophilusGameScene`，实际看到场景地形、建筑、玩家与物资/撤离标记、中文距离。1.52 秒观察到 8 次底图渲染，符合 5 Hz 上限在采样边界的计数。暂停后控件为 `None`，观察窗口中渲染 0 次；返回菜单后相机和纹理各剩余 0 个。

键盘注入没有产生位移，本次不声称完成键鼠移动走图验收。未进行双客户端、物资拾取/补货全流程、独立构建或帧率性能验收。测试前备份单人存档，退出后恢复。
