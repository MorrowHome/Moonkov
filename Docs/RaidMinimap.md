# 远征小地图

远征时，`RaidHUD` 在右上角显示小地图。收起任务列表后仍可看地图。按 M 打开可缩放的战术地图。

- 小地图显示自身周围 240 × 240 米的地表。北向固定。白色箭头指向本地视角的水平方向。
- 金色方框显示普通物资箱。服务器 `TakenMask` 标记空箱时变灰并划线，补货后随快照恢复。
- 空心金框显示路线箱的位置。M 地图打开「补给」图层后可看两类箱子。抽屉在场景中就近查找。
- 青色圆标表示补氧站。战术地图上也会显示 O₂。标记使用设施的实际位置。
- 绿色菱形及圆圈表示撤离信标与范围；信标超出地图时显示边缘方向箭头。底部显示水平距离，不代表可行走路线。
- 小地图和战术地图共用 GL125 的静态卫星图。底图和标记使用相同的世界坐标投影。小地图只提交 UI 网格，撤离距离每 0.2 秒更新。
- 打开背包、大地图、任务详情或暂停菜单，以及死亡和结算时隐藏。缺少卫星图的地图仍显示导航标记。

这是地表概览。建筑内部和深井使用同一张平面底图。

## 编辑入口

- `Assets/Resources/Moonkov/RaidUI.uxml`：固定结构，可用 UI Builder 编辑。
- `Assets/Resources/Moonkov/UI/RaidMinimap.uss`：地图尺寸、位置、配色及周边仪表避让；氧气仪表位于左侧网络状态下方，撤离提示位于小地图下方。
- `Assets/Scripts/Gameplay/UI/RaidMinimapView.cs`：覆盖范围 `HalfRange`、投影与标记。修改显示边长时同步 UXML 的覆盖范围文字和 USS 比例尺宽度。
- 中文沿用 `MoonkovUI` 字符串表。小地图使用现有 CJK 源字体。
