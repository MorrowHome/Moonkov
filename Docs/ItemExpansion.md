# 18 种物品扩充

本批新增 6 种补给、4 种储物装备、8 种可出售战利品。所有物品共用现有背包、箱子、商店、撤离结算和存档链路；名称、图标与中文用途说明在物品界面中展示。

价格单位为月尘，按单件计算。表中的箱子表示有概率产出该物品，并非每次必出；“仅回收”物品不能从商店购买。

## 获取与操作

- 四类箱子沿用 `RaidLootProfile`：补给（`Supplies`）、医疗（`Medical`）、工业（`Industrial`）、装备（`Equipment`）。服务器根据箱型从加权池中抽取内容；可选抽取不重复同一条目，放不下的物品会跳过并尝试其他条目。补货使用相同物品池。
- 在行动中按 Tab 打开背包，拖动物品安排位置；右键可查看说明、使用补给、装备或打开容器。新物品均有对应图标，说明包含占地、重量、堆叠、效果或储物分隔。
- “健康 / 宇航服状态”页支持新补给：治疗使用首件可取用的医疗用品；进食、饮水选择当前可用的对应补给；补氧显示下一瓶的恢复量。要指定消耗哪件物品，在背包中右键使用。数字 4 继续使用首件可取用医疗用品进行自动选部位治疗。
- 商店购买页显示可购买的新补给与装备，出售页显示持有的可交易物品及其说明。战利品须撤离带回仓库后出售；进行中的行动不能交易。装备在出售前须卸下并清空。

## 存档与服务兼容

新增物品使用新的字符串 code，沿用现有物品类型、`InventoryGraph` 层级及 JSON 字段，没有新增存档或数据库 schema。旧物品 code 和原有数据结构保持兼容，旧存档无需迁移；新物品也不会自动注入已有仓库。

单机与在线模式共用 `InventoryCatalog`、`ConsumableCatalog` 和 `ShopRules`。在线运行时，客户端、游戏服务器与 `MoonPersistence` 必须同步更新到包含新目录的二进制；旧服务不认识新 code，不能保证新物品的购买、校验和撤离结算。保存过新物品的存档也不应交给不含这些定义的旧版本读取。
