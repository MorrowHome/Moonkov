# 准心、射线与头部命中

`PlayerGhost.GetShotRay` 仍是客户端预测和服务端判定的共同入口。DollSinger 把镜头中心命中的 `AimPoint` 作为目标，服务端从原有稳定发射锚点及受限侧身位移发射。Halo 和 Revolver 现已改为实体弹道：共同射线只确定初始方向，伤害由服务端逐段碰撞决定，飞行中会下坠。参见 [弹道与网络显示](BallisticsAndNetworking.md)。模板中保留的 Hitscan 武器仍用射线判定。

模板角色的 CharacterController 只有 1.5 米高，而头骨在约 1.62 米，可见头部超出原判定胶囊。另外，远端 ClientProxy 会关闭移动 CharacterController，DollSinger 的 `m_Animator3P` 又为空；旧头部补丁直接返回，导致镜头射线穿过远端人物，将远处地面作为目标。从不同高度的服务端发射锚点朝该地面收束，就会与镜头在人物附近的路径偏离。

现从实际展示 Animator 解析 DollSinger 头骨，生成半径 0.17 米、中心位于头骨上方 0.06 米的头部 SphereCollider，并创建与移动胶囊尺寸一致的独立 Body hitbox。服务端和客户端都创建命中体，挂在角色根节点下；关闭代理的移动控制器或服务端展示模型不会关闭命中体。镜头取得人物表面的目标点后，显示与判定继续共享该点。头部尚未增加独立伤害倍率，身体命中体目前仍是胶囊近似。

`RaycastShot` 查询角色所在的 PhysicsScene，跳过发射者自己的碰撞体，再选择最近的墙体或目标；缓冲区满时扩容，达到上限则拒绝命中，避免漏掉遮挡物。服务端在本轮射击查询前同步物理 Transform。命中头部目前仍沿用武器伤害，没有额外爆头倍率。

验证入口：`Tools/Moonkov/Check Head Shots`。临时 PreviewScene 复现头部位于原胶囊上方的漏判，检查目标点与射线一致、头部命中、自身过滤及墙体遮挡；另外复现 DollSinger 移动碰撞体关闭的代理配置，检查镜头能取得人物表面、同一目标点能命中独立服务端模型。不启动 Play。该检查不证明移动目标在网络延迟下的命中表现；目前未实现历史命中体回溯。
