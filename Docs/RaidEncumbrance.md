# 局内负重

普通搜打撤中，携带重物会逐步影响行动。玩家可以继续携带高价值物品，也可以丢弃物品换取移动能力。仓库和正在查看的搜刮容器不算随身重量。装备、口袋和随身容器的内容都计入，嵌套物品只计一次。现有 45 公斤上限不变。

- 18 公斤及以下没有额外影响。超过 18 公斤后，影响随重量平滑增加。
- 到 45 公斤时，行走速度和跳跃高度降低 12%，冲刺速度降低 18%。冲刺耐力消耗增加 75%，停止冲刺后的恢复速度降低 35%。现有恢复延迟不变。
- 伤腿、饥渴和铁丝等原有限制继续生效。耐力针仍可防止冲刺疲劳，但不消除重量对移动的影响。赏金模式不应用这套负重惩罚。
- 背包重量使用已有显示。超过 18 公斤时标为较重。丢弃、转移或消耗物品后按真实库存更新，不使用客户端提交的重量。

服务端只在库存树或版本变化时重新计算重量。玩家和 PMC 使用各自的真实库存。数值按 0.01 公斤同步到客户端，原本的移动预测使用同一套规则。没有增加存档字段或新 RPC。联网双方需要使用相同版本。

## 验证

`RaidEncumbranceChecks.Run()` 的 19 项检查覆盖真实库存转移、重量变化、移动、冲刺疲劳、伤腿、耐力针和赏金模式隔离。原健康、战术物品服务端和局内库存检查通过。Unity 编译通过。

单 Editor 的隔离单人档案使用真实出战和局内丢弃请求。23.85 公斤时，服务端和本机客户端均读取 23.85 公斤，冲刺速度约 5.13。连续丢弃两组月尘后，库存与双方状态均为 17.85 公斤，负重提示恢复普通状态，冲刺速度约 5.34。使用实际输入，未改角色位置、重量或耐力。实际战局截图在忽略目录 `LocalData/Encumbrance/heavy-raid.png`。

上面的速度是本次单人环境中的观察值，不代表完整平衡或帧率验收。实体键鼠、独立联网客户端和 Player 构建仍未验证。重量阈值和惩罚幅度需要后续根据完整战局试玩调整。
